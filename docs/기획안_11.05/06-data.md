## 2. 업무상 서로 섞지 않아야 할 상태/관계

1. **공통 강의 ≠ 분반 ≠ 수강 확정 건.** 공통 콘텐츠를 분반들이 공유하고, 담당 강사 분반의 활성 수강 건으로 남은 자리를 계산한다. 강사별 합산 제한은 적용하지 않는다(D-52).
2. **분반의 빈자리 ≠ 대기자의 확정 전 상태.** 강의별 단일 FIFO 대기열에서 자리가 반환되면 1순위가 **초대 없이 즉시 확정**된다(D-53·54).
3. **대기 신청 시각 ≠ 수강 확정 시각.** 수강 30일의 기산은 확정 시각이며, 수료·취소·만료 뒤 같은 강의 재신청은 불가하다(D-55).
4. **차시 완료 ≠ 최종 과제 제출 ≠ 평가 시작 ≠ 수료 승인.** 제출만으로 수료되지 않으며 평가 시작은 수정 잠금을 만든다.
5. **단순 수정/임시저장 ≠ 정식 재제출.** 평가 기한 7일을 새로 계산하는 것은 최초 제출·반려 후 정식 재제출뿐이다.
6. **수강기간 만료 ≠ 평가 종료.** 기간 내 제출물은 만료 뒤에도 공식 평가하며 그동안의 점유/반환 기준을 분리한다.
7. **정원 반환 ≠ 수료 취소.** 수료자는 자리 반환 이후에도 강의 영상을 무제한 재시청한다.
8. **평가 초안 ≠ 완료된 공식 피드백.** 강사 변경 시 분반 담당자를 변경하고 진행 중 평가·잠금·기한을 새 담당자에게 인계한다(D-59).
9. **재신청 불가 ≠ 이전 개인 기록 삭제.** 재수강이 없는 이번 MVP에서는 D-36·D-44·FR-056을 실행하지 않는다.
10. **현행 사이트 알림 ≠ 인증 메일.** 서비스 이벤트 알림은 사이트 내에서만, 가입·복구 인증 이메일은 유지한다(D-57).
11. **폐기/확장 상태 ≠ MVP 상태.** 수료 철회·무효·배지 유예는 폐기, 신고·개인 제작 강의·오반려 정정은 확장이다.

## 3. DB 설계 시 검증할 항목 (기획 검증, 실제 DB 변경 지시 아님)

- [ ] 공통 강의·3차시·분반·현재 담당 강사·수강 확정 건의 논리 관계 및 재생 시간 60% 차시 완료 기록.
- [ ] 분반 정원 1~30과 활성 건 점유·남은 자리 최대 분반 자동 배정·동률 기본값 확인. **강사 합산 정원 검사 제외**.
- [ ] 강의별 FIFO 단일 대기열, 반환 즉시 1순위 자동 확정, 사이트 알림, 중복 확정 방지. **초대/수락/48시간 데이터 제외**.
- [ ] 수강 확정 시각+30일, 수료·취소·만료 후 동일 강의 재신청 차단, 평가 진행 중 자리 점유와 결과에 따른 반환.
- [ ] 최종 과제 `미제출/평가 대기/진행 중/반려/승인`, 수정 잠금, 평가 시작 취소, 7일 기한·48시간 이하 임박 표시.
- [ ] 담당 강사 교체 시 **분반 담당 변경** 및 진행 중 초안·잠금·평가 기한 승계. 수강생의 분반 간 강제 이동은 제외.
- [ ] 강사 통계는 **현재 4개 숫자**(분반별 수강 중·수료·반려·평가 대기)만. 월별 추이/과거 스냅샷 설계 제외.
- [ ] 카테고리·강의·영상 시드 데이터와 관리자 강사 계정/분반 관리 권한 구분.
- [ ] 이미지 원본 크기, 미디어 원본 접근/삭제, 비공개 작성자·담당 강사 권한 차단.
- [ ] 탈퇴·댓글 익명화·사이트 알림·문의·단일 세션과 신고 [확장]의 경계.
- [ ] **수료 철회·무효/유예 상태**, **재수강 삭제·보관 전환**, **48시간 초대·이메일 알림**이 현행 설계에 혼입되지 않음.

> 이 문서는 **2026-11-05 기획 논리 기준**이다. 실제 운영 DB/DDL의 존재나 일치 여부를 보증하지 않는다. 물리 스키마 개정은 DB 담당자의 별도 검토·승인을 따른다.
