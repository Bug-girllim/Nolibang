## 정책 적용 우선순위

**2026-11-05 D-51~D-59 > 2026-10-31 D-34~D-50 > 2026-10-30 통합 기준 > 이전 기록.**

- 공통 강의 분반: 정원 1~30, 담당 강사가 있는 분반 중 **남은 자리가 가장 큰 분반**으로 배정. 강사 합산 30건 제한 없음(D-52).
- 공통 강의별 **단일 FIFO 대기열**, 자리 발생 즉시 1순위 수강 확정 + 사이트 알림. 초대·수락·48시간 절차 없음(D-53·54).
- 같은 강의는 수료·취소·만료 후 재신청 불가(D-55). 재수강 회차/기록 삭제·보관 정책은 보류.
- 평가 시작·초안·승인/반려 흐름 유지. 평가 시작 시 수정 잠금(D-56).
- **사이트 알림만** 사용(평가 결과·자동 확정·수료). 가입 인증·계정 복구 메일은 별도(D-57).
- 강사 통계는 분반별 **현재** 수강 중·수료·반려·평가 대기 건수(D-58).
- 관리자는 강사 계정·분반 운영·대기열 조회·관리자 홈을 제공하고 카테고리·강의는 시드 데이터로 운용(D-59).

## 기획 집계와 해석 주의

- 11-05 기획 집계: **현행 FR 42개**(P0 19, P1 12, P2 8, 확장 3), **NFR 9개**, 합계 **51개**. `FR-011`·`FR-014`는 이번 MVP 범위 제외, `FR-056`은 보류. 과거 집계는 변경 이력으로만 유지한다.
- 개별 문서의 **10월 날짜는 해당 자료의 작성/조사 시점**을 뜻한다. 이 묶음의 정책 스냅샷은 모두 **2026-11-05**를 따른다.
- 충돌 시 **현행 결정이 우선**, 이전 결정 본문은 [이력]으로 해석한다. 확장·미정·보류 항목을 자동으로 MVP 확정 처리하지 않는다.
- DB 추적표의 17개 테이블은 당시 **설계 참고안**이다. SQL 적용 여부는 검증하지 않았으며 DB 변경 작업은 담당자의 책임이다.
