# 02. 역할별 구체적 사용자 시나리오 · 업무 흐름

> **[2026-11-05 MVP 단순화 결정 D-51~D-59 · 이 문서의 모든 앞선 기준보다 우선]** ① 강사 계정은 관리자가 **임시 비밀번호로 즉시 생성**(메일 설정 링크 없음, 첫 로그인 시 비밀번호 변경, D-51·FR-012) ② 공통 강의 분반은 여러 개·정원 1~30 유지, 배정은 **남은 자리가 가장 큰 분반** 한 줄 규칙, **강사 합산 30건 검사 삭제**(D-52·FR-052) ③ **단일 대기열(FIFO)** 유지, 자리가 나면 **1순위를 즉시 수강 확정 + 사이트 알림**, 초대·수락·48시간 단계 없음(D-53·FR-053) ④ 수강 취소 → 자리 반환 → **대기 1순위 자동 확정**(D-54·E6) ⑤ 같은 강의는 **수료(D-35)뿐 아니라 취소·만료한 강의도 이번에는 재신청 불가**(D-55·FR-055 P1) — 재수강 기록 삭제(D-36)·이전 시도 보관(D-44·FR-056)은 대상이 없어 보류 ⑥ 평가는 **시작(잠금) → 초안 → 승인/반려**, 시작 취소, 마감 임박·기한 초과 경고 유지(D-56·FR-023·030·031) ⑦ 알림은 **사이트 알림만**: 평가 결과(승인/반려)·대기→자동 확정·수료, **이메일 알림 없음**(D-57·FR-035) ⑧ 강사 통계는 **현재 숫자만**: 분반별 수강 중·수료·반려·평가 대기 수(D-58·FR-051) ⑨ 관리자 MVP는 **강사 계정·분반(생성·담당·정원)·대기열 조회·관리자 홈**, 카테고리·강의는 **시드 데이터**(D-59). 결정 상세는 `05-policy.md` §14. 아래 본문에 남은 48시간 초대·합산 30건·재수강 회차·월별 통계 문구는 **결정 이력**으로만 본다.

> **[최종 통합 기준 · 2026-10-30 / 변경사항 PDF 우선]** 동일 주제에서 기존 문서와 충돌하는 내용은 `놀이방_LMS_채팅확정_변경사항_20261030_통합갱신본(2).pdf` 01~09장의 최종 결정으로 대체한다. **강의당 3차시, 담당 강사 평가·필수 피드백 후 수료, 수강 확정부터 30일, 강의별 단일 대기열·48시간 초대, 공통 분반/강사 정원, 강사 통계 P0**가 현행 기준이다. **과제 제출 즉시 자동 수료, 수료 철회·14일/30일 배지 유예, 무효 후 재수료 보완기간은 폐기**한다. 신고·준강사는 기존처럼 [확장]이며 **개인 제작 강의는 이탈 대응을 포함해 기능 전체가 [확장]**이다(10-31). 10-30 통합에서 변경된 P등급은 강사 통계 P1→P0였고, **10-31 팀 결정으로 분반 자동 배정·정원·단일 대기열·48시간 초대·30일 수강기간은 P0, 재신청 제한은 P1**로 지정했다. 그 밖에 기존 등급이 없는 항목은 임의로 P0로 지정하지 않는다. 구 D-xx·FR-xxx의 대체된 문구는 현행 정책이 아닌 결정 이력으로만 본다.

## 1. 학습자 USER 시나리오

### U-01. 회원가입 및 이메일 인증

**정상 시나리오**

1. 방문자가 회원가입을 선택한다.
2. 아이디·비밀번호·실명·이메일을 필수로 입력하고 닉네임을 선택적으로 입력한다. 미입력 시 “형용사 + 동물명사 + 1~999” 방식의 공개 닉네임이 자동 생성됨을 안내한다.
3. 시스템이 아이디·닉네임의 중복을 검사한다. 닉네임 미입력 시 중복되지 않는 “형용사 + 동물명사 + 1~999” 조합을 무작위로 생성한다.
4. 입력한 이메일로 인증을 전송하고 회원이 인증을 마친다.
5. 인증 완료 후 USER 계정을 저장한다.
6. 가입 완료 화면에서 로그인 화면으로 이동하며, 자동 로그인은 하지 않는다.

**예외 시나리오**

- 필수 항목 누락, 아이디 중복, 입력 닉네임 중복, 이미 가입된 이메일, 탈퇴 후 30일이 지나지 않은 이메일, 이메일 인증 실패/만료 시 가입을 완료하지 않는다.
- 닉네임 미입력은 가입 실패 사유가 아니다. 자동 생성된 공개 닉네임이 기존 회원과 충돌하면 다른 조합을 생성한다. 공개 댓글·작품에 실명 또는 로그인 아이디를 대신 노출하지 않는다.
- 메일 발송 실패 및 저장 실패 시 가입 성공으로 처리하지 않는다.

**추가 결정:** [확정] 가입 직후 로그인 화면 이동(자동 로그인 없음), 닉네임 선택·중복 금지, 미입력 시 형용사+동물명사+1~999 자동 고유 닉네임 생성.


### U-02. 아이디 로그인·이메일 계정 복구·로그아웃

**정상 시나리오**

1. 학습자가 아이디와 비밀번호로 로그인한다.
2. 시스템이 인증과 USER 권한을 확인한다.
3. 해당 계정의 첫 로그인이라면 취미 탐색 화면으로 이동하고, 그 뒤 로그인은 메인 홈으로 이동한다.
4. 동일 계정이 다른 기기에서 로그인하면 기존 기기의 로그인 상태가 종료된다.
5. 로그인은 마지막 활동 후 1시간 동안 이용하지 않으면 만료되며, 영상 학습 화면의 재생·일시정지 중에는 정해진 범위에서 로그인 상태가 유지된다.
6. 브라우저를 종료한 뒤 재접속하면 다시 로그인하며, 로그인 상태가 만료되면 홈으로 이동한다.
7. 아이디 찾기·비밀번호 재설정은 가입 이메일 인증을 거쳐 진행한다.

**예외 시나리오**

- 비밀번호 불일치·계정 비활성화·직접 URL 무단 접근은 거부한다.
- 이메일 인증 불일치 또는 만료 시 계정 복구를 완료하지 않는다.
- 다른 기기 로그인으로 종료된 기존 세션은 보호 기능에 접근할 수 없다.
- 브라우저 종료 후 재접속에는 다시 로그인이 필요하다. 종료 직후 내부 로그인 정보가 어떻게 정리되는지는 개발 설계에서 확인한다.
- 일시정지 중 연장은 일시정지 시작 후 최대 2시간까지이며, 이후에는 1시간 유휴 규칙을 적용한다.
- [확정 D-08] 비회원은 메인 홈·취미 탐색·세부 취미 소개·강의 상세 소개까지 볼 수 있다. 수강 신청·영상·작품 게시판·댓글은 로그인 후 이용한다.

**추가 결정:** [확정] 첫 로그인 취미 탐색/이후 홈, 다중 기기 불허, 1시간 유휴 로그인 만료, 영상 재생·일시정지 중 정해진 범위의 로그인 유지, 브라우저 종료 후 재로그인, 만료 시 홈 이동.


### U-03. 대분류·세부 취미 탐색

**정상 시나리오**

1. 최초 로그인 학습자는 취미 탐색 화면으로, 이후 로그인 학습자는 메인 홈으로 이동한다.
2. 메인/탐색에서 운영 중 '미술·드로잉', '요리·베이킹'을 확인한다.
3. 운영 세부 취미인 색연필화·디지털 드로잉·디저트 만들기를 탐색한다.
4. 준비 중 '공예'는 목공·가죽공예·도자기·반지공예를 소개와 썸네일로 확인할 수 있지만 수강 신청은 불가능하다.
5. '사진·영상' 및 그 하위 '사진 촬영'·'영상 편집'은 일반 학습자에게 노출되지 않는다.

**예외 시나리오**

- 일반 사용자/강사가 비공개 카테고리 URL에 직접 접근해도 내용을 제공하지 않는다(MVP 관리자 전용).
- 준비 중 카테고리를 강의가 공개된 것처럼 표시하지 않는다.
- 삭제/숨김 상태나 데이터 조회 실패는 빈 상태 또는 접근 제한으로 처리한다.

**추가 결정:** [확정] 대분류 이름·상태 및 공예 하위 4개, 사진·영상 하위 2개. [확장] 비공개 분야 강의 담당 강사의 제한 열람.


### U-04. 세부 취미 소개·수준 선택

**정상 시나리오**

1. 색연필화 상세 페이지에서 소개와 학습 예시 등 준비된 콘텐츠를 확인한다. 입문·중급·고급 세 수준의 내 상태(미수강/수강 중/수료·배지)가 3칸으로 표시된다(P2).
2. 입문·중급·고급 가운데 본인의 경험에 맞는 수준을 자유롭게 고른다.
3. 입문 수준을 선행 수료하지 않아도 중급 또는 고급 강의에 신청할 수 있다.
4. 선택한 세부 취미·수준의 공개 강의로 이동한다.
5. 다른 취미는 독립적으로 수준을 탐색하고 배울 수 있다.

**예외 시나리오**

- 선택한 수준의 이용 가능한 강의가 없거나 제한 중이면 신규 수강을 허용하지 않는다.
- 세부 취미 자체가 준비 중/비공개 상태라면 수준 선택 후 수강까지 진행할 수 없다.

**추가 결정:** [미포함] 선택 수준을 프로필에 별도 저장·수정하는 기능은 MVP에 두지 않는다. 수준별 내 상태는 U-S02의 3칸 표시(P2, P-04)로 확인한다.


### U-05. 강의 상세·수강 신청·분반 지정

**정상:** 학습자가 취미·수준의 공통 강의를 열어 **3차시·최종 과제·수강기간 30일·정원 상태**를 확인한다. **대기자가 없고** 자리가 있으면 **담당 강사가 있는 분반 중 남은 자리가 가장 큰 분반**을 자동 지정받아 수강이 확정되고 **확정일부터 30일**이 시작된다(D-52). 만석이면 해당 **강의 전체 단일 대기열(FIFO)**에 선다. 자리가 나서 1순위가 되면 **즉시 자동으로 수강 확정**되고 사이트 알림을 받는다(D-53, 초대·수락 없음).

**예외:** 학습 중/대기 중 동일 강의 중복 신청 금지, **수료·취소·만료한 강의는 신청·대기 불가(D-35·D-55)**. 대기자가 있으면 빈자리가 있어도 신규 신청자는 대기열 끝으로 간다. 담당 강사가 있는 분반이 없으면 신규 신청·대기 불가. 대기 취소 뒤 재신청은 끝순번. 다른 강의 수강은 가능하다. 별도 확인 팝업 없음(기존 D-08)은 접수 결과 확인과 구별한다.

**연결:** F-03/F-17, FR-015, U-16, 05 §4.

### U-06. 하나의 강의 안에서 필수 3차시 학습

**정상:** 강의에 배정된 학습자는 차시 1→2→3(자유 이동 가능 범위는 강의 구성에 따름) 각각의 영상에 대해 **실제 재생 시간 60%**를 달성하면 해당 차시를 완료한다. 세 차시가 모두 완료되어야 최종 실습 제출이 가능하다. 완료 뒤 다음 차시나 실습으로 자동 이동하지 않는다. 완료/진도는 그 **수강 회차**에 귀속한다.

**예외:** 한 차시만 완료하거나 3차시 중 하나가 누락되면 최종 과제 제출 불가. 일시정지는 시청 시간 미산입, 새로고침·재생 반복의 비정상 진도 중복 기록 금지. 수강 확정 30일 만료 이후 새 제출 불가. 수료자는 기간이 끝나더라도 영상 무제한 다시 보기 가능. 새 회차는 이전 차시 진도를 이어받지 않는다.

### U-07. 최종 과제 제출·평가 대기·수정·재제출

**정상:** 세 차시 완료 후 수강기간 30일 안에 작품 이미지를 정상 제출하면 상태가 **평가 대기**가 된다. **이때 수료·배지 없음.** 담당 강사가 아직 **평가 시작**을 누르기 전까지는 기간 안에서 학습자가 과제 내용을 수정·임시저장할 수 있다. 수정만으로 최초 제출 시각이나 평가 마감은 바뀌지 않는다. 강사가 평가 시작하면 즉시 수정이 잠긴다. 반려 확정 시 사유를 확인하고 **기간 안에서 횟수 제한 없이 `정식 재제출`**을 할 수 있다. 정식 재제출만 새로운 7일 평가 시계를 시작한다.

**예외:** 이미지 1~5장/원본 장당 50MB·JPG/PNG/WebP 등 기존 파일 정책 미충족 시 미제출. 동시에 평가 대기 최종 과제 1개만 허용. 30일 지나면 수정/신규 제출/재제출은 불가하나 **만료 전에 제출된 과제는 담당 강사가 계속 평가**한다. 평가 대기 중 수강 취소 금지; 반려 후 대기 중이 아니라면 취소 가능. **수료 승인된 최종 과제의 작성자 직접 삭제 및 승인 뒤 수정 범위는 PDF에서 미확정**이며, 과제 삭제로 수료를 즉시 철회하는 구 D-32 규칙은 폐기한다.

### U-08. 강사 평가·피드백 후 수료·배지 취득

**정상:** 담당 전문강사는 제출된 과제를 **7일 안에 평가**하고, 승인할 때 **공식 피드백 50자 이상**을 반드시 작성한다. 승인 순간 강의 수료가 확정되어 수준 배지가 발행되고 해당 수강 정원이 즉시 반환된다. 학습자는 승인 결과/피드백 알림을 보고 **수료한 강의의 영상을 무제한** 다시 볼 수 있다. 같은 취미·수준의 인정 강의 1개 수료로 수준 배지, 세 수준 각각 1개로 마스터 배지를 얻는다.

**반려:** 반려 사유(최소 길이 필수, D-47)가 있어야 반려 완료. 반려 후 30일 수강기간이 남으면 횟수 제한 없이 재제출, 만료 후 반려되면 같은 회차 재제출은 불가(정원 반환). 반려·승인 결과를 강사가 사후에 바꾸는 **오반려 정정은 [확장](D-37)**이며 MVP에서 제공하지 않는다.

**주의:** 제출만으로 수료되지 않으며, 강사 피드백은 수료 뒤 부수 업무가 아니라 **승인 필수 조건**이다. 예전 14일/30일 배지 유예·수료 철회 제도는 폐기됐다.

### U-09. 작품 게시판 공개·비공개 전환 및 조회

**정상 시나리오**

1. 학습자가 최종 과제를 게시판에 공개할지 선택한다(기본 비공개).
2. 공개 설정한 유효 최종 과제는 해당 취미/분야의 작품 게시판에 표시된다.
3. 최종 과제의 공개 게시물과 별도 일반 작품 게시물을 구분해 관리한다. 일반 작품은 여러 개 등록할 수 있고, 등록해도 수료·배지에 영향이 없다.
4. 게시판에서 대분류/세부 카테고리별 목록을 선택하고 검색·필터·정렬한다. 파스텔화→미술·드로잉 게시판은 향후 예시이며 현재 운영 취미에 포함되지는 않는다.
5. 최종 과제 작성자는 정상 제출한 작품의 내용·이미지·공개 설정을 수정할 수 있다. 기존 수료·수료일·피드백·댓글·좋아요는 유지하되 수정일과 “수정된 작품” 표시는 추가한다.
6. 일반 작품 등록 시 **운영 중 세부 취미**를 선택하고(D-29) **수준은 입문이 기본**이다. 그 취미의 현재 유효 배지가 없으면 입문으로 고정하며, 배지가 있으면 **보유한 최고 수준 이하**에서 선택한다. 게시물 댓글 작성자의 권한은 확정된 취미·수준 태그로 검증한다.
7. **일반 작품 제목을 직접 입력**하고 JPG/PNG/WebP 이미지 1~5장(입력 원본 장당 50MB 이하)을 등록한다(D-18·D-22). 등록 화면은 선택 취미의 **본인 최근 공식 피드백 1개 전문**을 보여주며, 학습자가 ‘이번 작품에 참고한 피드백’을 선택하면 **작품과 피드백의 참조를 실제 저장**한다(D-17). 성장 타임라인에서 이 연결을 확인하고 한 줄 회고를 남길 수 있다(D-14). **관리자 작품 숨김만으로 본인 피드백 열람을 차단하지 않으며(Q-02)**, 신고로 공식 피드백 자체가 숨김 또는 과제 무효 상태인 경우는 확장 정책으로 구분한다. 본인에게 유효한 참고 피드백이 없으면 ‘참고 가능한 최근 공식 피드백이 없습니다’ 안내와 함께 선택을 비활성화한다.

**예외 시나리오**

- 비공개 원본은 URL 직접 접근까지 서버에서 차단한다.
- 관리자 숨김 작품은 일반 이용자에게는 비공개이나 **작성자와 현재 담당 강사**는 최종 과제·공식 피드백을 계속 열람할 수 있다(Q-02).
- 관리자 숨김만으로 수료가 취소되거나 최종 과제 재제출 자격이 생기지 않는다(Q-02).
- **[폐기]** 관리자 과제 무효로 인한 수료 철회·배지 유예·보완기간은 실행하지 않는다.
- 수강하지 않은 취미도 일반 작품으로는 등록할 수 있다(최종 과제는 불가). 단 준비 중·비공개 취미는 선택할 수 없고, 취미가 나중에 준비 중이 돼도 기존 작품은 유지된다(D-29). 다만 배지가 없다면 그 작품의 수준은 입문으로 고정한다. **입문 태그라고 비배지 회원에게 댓글 작성 권한이 열리는 것은 아니다.**
- [D-22] 일반 작품도 이미지 1~5장·원본 장당 50MB·JPG/PNG/WebP를 따르고 **일부 파일 실패 시 게시가 완료되지 않는다**. 이 실패는 기존 수료·배지를 변경하지 않는다.
- [D-17/Q-02] **관리자 작품 공개 숨김만으로는 작성자의 성장 기록·공식 피드백 원문 접근이 사라지지 않는다.** 이후 피드백 자체가 신고로 숨김 상태가 되면 참조·원문 제한을 별도로 적용한다([확장 D-33]; 과제 무효 연동 D-30은 **폐기**). 본인 최종 과제 삭제·탈퇴, 또는 재수강 시 보관하지 않은 이전 회차의 반려 사유 삭제(D-44)로 원 피드백이 삭제되면 참고 연결을 해제한다.
- [확장 D-33] 신고가 처리 중인 작품은 **기존에 열어둔 수정 화면에서 전송하더라도 저장 단계에서 수정이 거부**하고 처리 후 자동 해제된다.
- 관리자 숨김 작품은 작성자가 수정할 수 있으나 숨김 해제는 관리자만 할 수 있다(Q-01). 기존 수준 태그는 배지 상실만으로 자동 변경하지 않고, **새 등록/태그 수정 시점**에 현재 배지 권한으로 재검증한다. 이전 이미지 원본의 정리 방법은 개발 설계에서 확인한다.

- [D-32] 일반 작품 삭제는 수료와 무관하다. 해당 작품의 댓글·좋아요와 **‘이번 작품에 참고한 공식 피드백’ 연결 관계(참조)만 삭제**하고 성장 기록에서 제외한다. **원본 공식 피드백 본문과 최종 과제는 보존**하며, 피드백이 붙은 최종 과제 자체를 삭제하는 경우만 별도 D-32 처리를 따른다.

**추가 결정:** [확정] 최종 과제/일반 작품 구분, 복수 일반 작품, 취미·수준 선택, 댓글에 해당 배지 기준 적용, 정상 수정 시 수료·기존 피드백·댓글·좋아요 유지. 미수강 취미의 일반 작품 등록 허용(과제는 불가), 관리자 숨김 작품 수정 가능·숨김 해제는 관리자만(Q-01), 작품 삭제(D-32). [확장 D-33] 신고 처리 중 수정 잠금.


### U-10. 공개 작품 좋아요·배지별 댓글

**정상 시나리오**

1. 로그인 사용자는 공개 작품에 좋아요를 누를 수 있으며 자기 작품에도 가능하다.
2. 작품마다 회원별 좋아요는 중복 생성하지 않고 취소/재등록할 수 있다.
3. 댓글 작성은 해당 취미의 유효 배지로 권한을 검사한다(유예 배지는 후속 확장)(입문→입문, 중급→입문/중급, 고급→모든 수준).
4. 본인이 작성한 댓글은 본인만 수정·삭제할 수 있다. 작성자는 자기 작품에 달린 댓글에 배지와 상관없이 답글을 달 수 있다.
5. 댓글과 1단계 대댓글을 제공한다. **작성자가 자발적으로 삭제한** 부모 댓글은 본문만 “삭제된 댓글입니다”로 치환하고 타인 답글을 유지한다. **작성자가 탈퇴했지만 스스로 삭제하지 않은** 댓글은 본문 식별정보를 비식별 처리(재식별 우려 시 본문 전체 대체)한 뒤 익명 보존하고 작성자명을 “--탈퇴한 사용자 입니다--”로 표시한다(D-25, 상세 U-15).
6. **[확장 D-33]** 공개 작품·댓글 신고는 도입 후에만 가능하며 신고 자체로 수료가 철회되지 않는다. **MVP 관리자는 공개 작품 숨김·복구만** 한다.
7. 배지 철회 후 새 댓글 권한은 재판정하되 정상 작성된 과거 댓글은 유지한다.

**예외 시나리오**

- 다른 세부 취미 배지로 댓글 권한을 대신할 수 없다.
- 타인의 댓글 수정/삭제는 금지한다.
- 비공개·관리자 숨김 작품에는 새 댓글을 쓸 수 없다.
- 탈퇴한 회원이 타인 작품에 남긴 댓글/좋아요는 작성자 연결을 제거하여 익명 보존한다. 게시물이 삭제되면 그 게시물에 연결된 반응 삭제 원칙이 적용된다.
- 일반 작품에서도 작성 시 선택된 취미·수준의 배지 기준으로 새 댓글 권한을 확인한다.
- 부모 댓글이 삭제돼도 다른 사람 답글을 삭제하거나 작성자를 임의 변경하지 않는다. **자발 삭제가 먼저였으면 탈퇴 후에도 본문을 복원하지 않고** “삭제된 댓글입니다”를 유지한다. 탈퇴한 작성자의 공개 표시명은 익명화한다. 신고 검토 중 숨김은 별도의 운영 상태다(확장 D-33).

**추가 결정:** [확정] 본인 작품 좋아요, 본인 댓글 수정·삭제, 자기 작품 댓글에는 배지 무관 답글, 1단계 대댓글·삭제 부모 표시, 일반 작품의 선택 취미·수준 배지 기준 댓글 권한.


### U-11. 공식 평가 결과·피드백·문의·복습 확인

**정상:** 3차시 완료 뒤 제출한 최종 과제는 아직 **평가 대기이며 수료가 아니다**. 담당 강사는 최초 제출(또는 반려 후 정식 재제출)로부터 **7일 내** 최종 평가해야 한다. 승인 시 공식 피드백 최소 50자(잘한 점/개선할 점/다음 연습은 가이드)와 함께 강의 수료를 확정하며 학습자는 알림함에서 승인 결과·피드백을 본다. 반려면 사유를 확인하고 남은 수강기간 안에 재제출한다. 복습 추천/확인은 기존 P2이며 수료 조건은 아니다.

**예외:** 피드백 작성 전에 작품을 수정·임시저장해도 7일 기한 초기화 없음. 48시간 이하 마감 임박/기한 초과를 표시한다. 30일 만료 후에도 기간 내 제출된 과제의 평가 의무는 계속된다. 공식 평가는 일반 댓글과 다르며 담당 전문강사만 가능하다. 직접 강사가 수강자에게 신규 개별 메시지를 보내는 기능은 없다. 강사 부재 시 관리자는 과거 Q-03a 방식으로 영향 대상에게 운영 이메일 수동 안내하되, 미평가 과제를 자동 수료시키지 않는다. 기존 1:1 문의는 담당 배정/권한 범위 안에서 유지.

### U-12. 작품·강사 피드백 신고 및 결과 확인 [확장 D-33]

> MVP 미포함(D-33). 신고 기능 도입 시의 흐름으로 보존한다.

**정상 시나리오**

1. 로그인 회원이 공개 작품, 댓글 또는 강사 피드백을 신고한다. 담당 강사는 담당 강의의 비공개 최종 과제도 신고할 수 있다(T-02).
2. 관리자가 신고를 접수·검토한다.
3. 관리자의 신고 조치 결과는 해당 신고 관련 이용자에게 이메일로 통지한다.
4. 로그인 중이라면 일반적인 피드백·댓글·답변 알림은 우측 상단 알림함에서 확인한다.
5. 관리자는 **현행 공개 작품 숨김·복구(Q-01/Q-02)**와 확장 신고 처리를 구별한다. **관리자 과제 무효→수료 철회는 폐기**됐으므로 신고로 자동 무효·철회 처리하지 않는다.

**예외 시나리오**

- 신고만으로 과제 무효/수료 철회가 발생하지 않는다.
- 완료된 일반 신고는 탈퇴 시 삭제하고, 진행 중 신고와 필요한 증거는 처리 완료까지 필요한 최소 신원정보와 함께 보존한다.
- 정식 이의제기·재검토 요청 화면은 MVP가 아닌 확장 기능이다.
- 이메일 발송 실패 처리/재전송 등은 개발 명세에서 결정한다.

**추가 결정:** [확장 D-33] 댓글·작품·피드백 신고는 MVP 제외. **관리자 과제 무효→수료 철회·무효 오판 정정은 폐기**다. 현행 관리자 공개 작품 숨김·복구의 결과 안내는 유지하며 학습자 정식 이의제기는 확장이다.


### U-13. [폐기 이력] 관리자 무효·수료 철회·배지 유예

2026-10-30 PDF 08장에 따라 기존 관리자 과제 무효로 수료를 철회하고 14일/30일 유예·보완기간을 부여하는 흐름은 **폐기**되었다. U-13은 시나리오 번호 추적용으로만 남기며 개발·시연 대상이 아니다. 현재의 **강사 최초/재제출 평가 반려**와 혼동하지 않는다.

### U-14. 학습 현황·성취·공개 프로필 조회

**정상 시나리오**

1. 나의 학습 현황에서 수강·차시·유효 최종 과제·수료·복습 이력을 본인만 확인한다.
2. 영상 학습 완료일과 강의 수료일(현재 유효한 과제 제출일)을 구분 표시한다.
3. 공개 프로필에는 본인이 획득한 배지를 표시한다. 닉네임 미입력 시에도 공개 이름은 자동 생성된 형용사+동물명사+숫자 닉네임이며 실명은 노출하지 않는다.
4. 작품 기록은 기본 비공개이며, 최종 과제·게시판 추가 작품의 공개를 선택할 수 있다.
5. 개인 성장 기록에서 수료용 최종 과제와 별도 일반 작품을 날짜순(최초 등록·유효 제출일)으로 조회한다. 작품마다 선택적 한 줄 회고를 남길 수 있으며 안내문은 ‘이전 작업보다 나아진 점이나 여전히 아쉬운 점은 무엇인가요?’이다(D-14).
6. 취미를 선택하면 상단에 그 취미의 ‘나의 첫 시작’과 ‘가장 최근 실습’ 썸네일 2개가 표시된다(D-13).
7. 공개 작품만 다른 사용자에게 노출하고 비공개 파일 원본 URL을 보호한다.

**예외 시나리오**

- 제3자가 학습 현황에 직접 접근하지 못하도록 차단한다.
- 수료 과제의 유효성·게시판 공개 상태·배지 권한은 별도 상태로 관리한다.
- **[확장]** 관리자의 무효·정정으로 배지·수료일이 변경되는 시나리오는 후속 도입 시 검토한다. **[현행]** 수료 확정 후 작성자 직접 과제 삭제(D-32)의 후처리·배지 영향은 미정이며 자동 철회하지 않는다.
- **[폐기 이력 D-16·D-30]** 이전 무효 과제 A의 오판 정정과 새 과제 B의 수료 판정 시나리오는 관리자 무효 제도 폐기와 함께 현행·확장 모두에서 제외한다(결정 이력으로만 보존).
- [D-17] 일반 작품에서 선택 저장한 참고 피드백은 성장 타임라인에서 연결해 보며, 숨김·삭제 피드백 원문에 접근할 수 없다.
- **[MVP]** 삭제된 작품은 성장 기록에서 제외된다(D-32). **[확장]** 무효 확정 작품 제외·오판 정정된 이전 과제 표시는 무효 기능 도입 후 적용한다.

**추가 결정:** [확정] 학습 현황 비공개, 배지 공개, 작품 선택 공개, 영상 완료일과 수료일 분리. [MVP 신규 확정] 최종 과제·일반 작품의 날짜순 성장 기록 + 선택적 한 줄 회고. 회고는 수료 조건 아님. [확정 D-13·D-14] 동일 취미 첫/최근 썸네일 요약, 회고 안내문 변경. [확장] 확대 비교·변화 분석.


### U-15. 학습자 회원 탈퇴 및 연관 데이터 삭제

**정상 시나리오**

1. 학습자가 계정 설정에서 회원 탈퇴를 선택한다.
2. 서비스가 삭제되는 데이터·복구 불가 가능성·30일 재가입 제한을 안내하고 **비밀번호 재입력**으로 본인 확인을 진행한다([확정 D-08]).
3. 최종 탈퇴 시 계정은 **탈퇴 처리해 로그인/재활성화를 차단**하고 실명·이메일·로그인 식별정보·인증정보를 제거 또는 비식별화한다. 개인 학습 기록은 삭제한다. 같은 이메일 재가입은 탈퇴 30일 후부터 가능하며, 이메일 원문 대신 재가입 확인값만 30일 보관한다.
4. 수강·진도·수료·배지·강사 피드백·추천 복습·복습 완료 이력을 삭제한다.
5. 해당 학습자의 과제 제출 원본·이미지 파일·공개 작품 게시물을 삭제한다.
6. 타인 작품에 남긴 **자발 삭제하지 않은** 댓글은 원 계정 연결을 끊기 **전에** 본문 속 이메일·전화번호·실명·외부 계정 등 식별정보를 확인하고 마스킹·대체한다. 나머지는 익명 보존하고 작성자명을 '--탈퇴한 사용자 입니다--'로 표시한다(D-25). 부분 마스킹 후에도 재식별 가능하면 **본문 전체 비공개/삭제·대체**하되 댓글 자리와 다른 이용자의 답글은 유지한다. 이미 자발 삭제한 댓글은 '삭제된 댓글입니다'를 유지한다.
7. 탈퇴자 댓글에 달린 다른 이용자의 답글도 유지한다. 다른 이용자의 이름은 변경하지 않는다.
8. 탈퇴자가 눌렀던 좋아요는 익명 반응/집계로 유지하되 회원별 좋아요 중복 방지·취소를 위한 식별·연결 기록은 탈퇴와 함께 정리한다.
9. [확장 D-33] 완료된 일반 신고는 삭제하며 진행 중 신고·관련 증거만 사건 처리 완료까지 예외적으로 보존한다. 신고자 신원은 필요한 최소 범위로만 유지한다.
10. [확장 D-33] 탈퇴자가 신고당한 작품·댓글이 진행 중 신고 대상이면 처리 완료까지 비공개로 보존한 뒤 삭제한다.
11. 탈퇴자의 1:1 문의는 **스레드 전체를 즉시 삭제**한다. [확장 D-33] 진행 중 신고가 있으면 스레드와 필수 증거를 비공개·접근 제한 상태로 보존한 뒤 **신고 처리 완료 및 법적 보존 필요성 확인 후 삭제**한다.

**예외 시나리오**

- 탈퇴된 계정의 비식별 껍데기가 남더라도 공개 댓글·익명 좋아요가 **원 계정 ID로 연결되어서는 안 된다**. 비식별 계정 행 존속과 작성자 연결 제거를 혼동하지 않는다.
- 탈퇴자 댓글을 남기는 것과 탈퇴자 계정·학습 기록을 보존하는 것을 혼동하지 않는다.
- [확장 D-33] 진행 중 신고의 처리가 끝나면 별도 법적 보존 의무를 확인하고 예외 보존한 신고/증거 및 필요한 신원 정보도 삭제한다.
- 탈퇴자의 공개 작품 자체는 삭제되므로 그 작품에 달린 댓글·좋아요 보존 여부는 작품 삭제 정책을 적용한다. 다른 사람의 작품에 남긴 댓글·좋아요만 익명 보존한다.
- 삭제가 일부 실패했을 때는 탈퇴를 완전히 처리한 것으로 안내하지 않으며, 재처리 방법은 개발 설계에서 정한다.
- [확정 D-25] 자동 탐지만으로 모든 식별정보를 제거했다고 보장하지 않는다. 확인이 어려운 본문은 공개 보존하지 않으며, 필요 시 관리자 점검으로 보완한다(이용자 신고는 확장 D-33). [확장 D-33] 진행 중 신고에 필요한 원문 증거만 비공개로 최소 보존하고 사건 종료 뒤 삭제 원칙을 따른다.

**추가 결정:** [확정] 작성자 연결 제거·개인정보 비식별 처리 후 댓글 본문 익명 보존(D-25)·익명 좋아요 집계 유지. [확장 D-33] 진행 중 신고/최소 신원 예외 보존. [개발 검증] 개인정보 파기 실패 재처리의 기술 상세.


### U-16. 단일 대기열·자동 확정·수강 취소 [신규 · D-53·D-54]

1. [USER] 만석인 공통 강의의 **단일 대기열**에 신청해 순번을 받는다.
2. [SYSTEM] 수료 승인·수강 취소·만료 반환·정원 증가로 자리가 생기면 **대기 1순위를 즉시 수강 확정**한다(분반은 남은 자리가 가장 큰 분반). **사이트 알림**만 보낸다(이메일 없음, D-57).
3. [USER] 자동 확정 시각부터 **30일 수강기간이 시작**된다. 초대·수락·48시간 단계는 없으므로, 수강을 원하지 않으면 대기 중에 스스로 대기를 취소해야 한다. 관리자는 대기열을 조회만 한다.
4. [USER] 대기를 취소하고 재신청하면 순번은 끝으로 이동하며 동일 강의 수강 중/대기 중 중복 신청 불가.
5. [USER · E6] 수강 중(평가 대기·진행 제외)인 학습자가 수강을 취소하면 ‘취소한 강의는 다시 신청할 수 없습니다’를 확인한 뒤 취소된다. **자리 반환 → 대기 1순위 자동 확정 → 그 학습자에게 사이트 알림**(D-54).

### U-17. 같은 강의 재신청 불가 [신규 · D-55]

1. [USER] 수료한 강의(D-35), **취소한 강의, 기간이 만료된 강의**는 세부 취미 화면에서 신청·대기 버튼 대신 ‘다시 신청할 수 없습니다’ 안내를 본다.
2. [USER] 반려는 수강기간 안의 정식 재제출로만 이어진다. 만료 후 반려되면 그 강의는 종료되며 재신청할 수 없다.
3. [SYSTEM] 새 회차가 생기지 않으므로 이전 기록 삭제(D-36)·이전 시도 보관(D-44·FR-056)은 발생하지 않는다.

> **[보류 이력 · 재신청 허용 시 재검토]** 아래 1~6은 2026-10-31 기준 재수강 흐름이며 현행이 아니다.


1. [USER] 11/1 수강 확정 후 11/12 취소했다면 11/1+30일 이전에는 같은 강의 신청/대기 불가.
2. [USER] 수강기간 내 반려 확정 후 평가 대기가 아니면 취소 가능하고 정원이 반환된다. 반려 후 정식 재제출 시에는 정원 계속 점유.
3. [USER] 원래 회차 30일 이후 반려가 확정되면 **반려 결과가 확정된 시각**부터 새 회차 신청 가능. 이전 과제 평가 미확정 상태에서는 불가.
4. [USER] 새 회차가 확정되기 전, 이전 회차 최종 과제를 **‘이전 시도로 일반 작품에 보관’**할지 선택한다(D-44, FR-056). 보관하면 이미지·설명·회고·공개 상태·타인 댓글/좋아요·반려 사유 원문이 본인 일반 작품으로 이동한다.
5. [SYSTEM] **새 회차 확정 순간**(즉시 확정 또는 초대 수락) 이전 회차의 개인별 진도·차시 기록·보관하지 않은 과제·반려 사유를 삭제하고 3차시를 처음부터 시작한다(D-36). 미보관 공개 게시물에 타인 댓글이 있으면 ‘작성자가 삭제한 작품입니다’ 자리 표시로 타인 댓글·답글을 보존한다. 과거 집계 강사 통계 불변.
6. [예외] **수료 승인된 강의는 재수강할 수 없다(D-35).** 대기 신청·초대 미수락·대기 취소로는 이전 기록을 삭제하지 않는다.

## 2. 강사 INSTRUCTOR 시나리오

### T-01. 관리자 등록을 통한 강사 최초 접속

**정상 시나리오**

1. 전문 외부 강사는 관리자가 학습자 계정과 별도의 INSTRUCTOR 계정을 만들어 제공한다.
2. 관리자는 해당 강사에게 세부 취미 활동 권한을 부여한다.
3. 관리자는 공통 강의의 **분반별 공식 담당 전문강사 1명**을 배정한다(강사 합산 30건 검사 없음, D-52).
4. 관리자가 아이디·실명·이메일·**임시 비밀번호**로 계정을 만들면 즉시 활성화된다. 관리자는 임시 비밀번호를 강사에게 직접 전달하고, 강사는 첫 로그인 시 **새 비밀번호로 변경**한 뒤 담당 강의를 확인한다([확정 D-51], 구 D-10 메일 링크 대체).
5. [확장] 학습자가 마스터 배지를 획득한 뒤 준강사 신청을 하면 관리자가 승인해 기존 학습자 계정에 준강사 권한을 추가하는 흐름을 설계한다.
6. [확장] 준강사는 학습을 병행하며 담당 강사의 보조 또는 공백 시 대리 활동을 할 수 있도록 장기 기획에 남긴다. 이번 MVP는 역할/메뉴 설계안만 남기고 실제 신청·승인·대리 기능을 구현하지 않는다.

**예외 시나리오**

- 준강사는 전문 강사와 동일한 별도 전용 계정을 무조건 생성하지 않으며 기존 USER 계정 기반이다.
- 취미 활동 권한만으로 모든 비공개 과제에 접근하거나 개별 강의의 공식 피드백을 작성할 수 없다.
- MVP에서는 준강사의 신청·승인·강의 대리·비공개 제출물 접근을 실제 기능으로 제공하지 않는다. 강의당 담당 INSTRUCTOR 1명 원칙을 그대로 유지한다.
- 확장 단계 준강사의 공식 피드백 대행 허용 범위·배지 유예/철회 시 자격 처리는 아직 미결정이다.
- 첫 로그인에서 비밀번호를 변경하기 전에는 다른 화면을 이용할 수 없다. 강사가 비밀번호를 잊으면 관리자가 임시 비밀번호를 재발급한다. 메일 설정 링크·링크 만료·재발송은 없다(D-51).

**추가 결정:** [확정] 전문 강사 관리자 계정 발급, 준강사 USER 병행 기획. [MVP 제외] 준강사 신청·승인·보조·대리 구현. [확장 미정] 대행 권한·배지 회수 시 자격. [확정 D-51] 임시 비밀번호 즉시 생성·첫 로그인 변경(구 D-10 대체). [개발 검증] 임시 비밀번호 해시 보관·변경 강제.


### T-02. 분반 담당 강사 평가·시작 잠금·피드백·반려

1. 강사는 로그인 직후 본인 담당 강의·분반을 확인하고 과제를 **대기/진행 중/완료** 탭으로 확인한다.
2. 대기 과제의 **최초 제출 또는 정식 재제출+7×24시간**을 마감으로 보며, **48시간 이하 임박**과 **기한 초과**를 표시한다. 단순 과제 열람은 잠금이 아니다.
3. 담당 강사가 **평가 시작** 버튼을 눌러 `진행 중`으로 만들 때 학습자 수정이 즉시 잠긴다. 평가 내용을 아직 작성하지 않았다면 같은 강사가 **시작 취소**하고 `대기`로 되돌릴 수 있다(마감 고정).
4. **수료 승인:** 필수 피드백 50자 이상 작성 후 승인. **반려:** 반려 사유 작성 후 반려. 다른 강사나 일반 관리자에게 공식 평가 권한 없음.
5. 수료 승인 시 수료·배지·영상 무제한 다시 보기 및 정원 반환. 반려 시 미수료, 30일 남았으면 재제출 가능(횟수 제한 없음).
6. 평가는 30일 만료 후에도 기간 안에 제출된 과제라면 계속 진행해야 하며, 그동안 정원 점유. 강사 변경 시 미완료 평가·작성 중 피드백 초안·잠금·마감은 새 담당에게 인계된다.
7. 강사는 학습자 1:1 문의에 응답할 수 있으나 **수강생에게 일방 메시지/알림을 직접 발송하는 기능은 제공하지 않는다**. (개인 제작 강사 지연 대응 Q28은 [확장 D-45].)

### T-03. 학습자 질문 답변·피드백 수정

**정상 시나리오**

1. 강사는 담당 강의 학습자의 1:1 문의와 공개 작품의 질문 댓글을 확인한다.
2. 1:1 문의에는 문의 스레드로, 공개 작품 질문에는 댓글로 답변한다. 공식 피드백은 별도의 제출물당 1개 기록으로 유지한다.
3. 새 질문/답변은 오른쪽 위 알림함에서 표시된다.
4. 강사 본인은 권한이 있는 공식 피드백을 수정할 수 있다.
5. 세부 취미 권한이 있지만 특정 강의를 담당하지 않은 강사도 그 취미의 공개 작품에 일반 댓글을 작성할 수 있다.

**예외 시나리오**

- 담당하지 않은 비공개 제출물을 조회하거나 공식 피드백을 작성할 수 없다.
- [확장 D-33] 피드백 신고 시 관리자는 직접 원문을 수정하지 않고 숨기거나 작성자에게 수정 요청한다.
- 담당 해제 후 과거 피드백 수정 불가([확정 D-08]).
- 1:1 문의는 텍스트만 가능하다(문의 신고는 확장 D-33). 답변은 1주일 내 권장이며 경고 대상이 아니다.

**추가 결정:** [확정] 담당 외 강사의 같은 취미 공개 작품 일반 댓글 허용, 댓글형 질문/답변, 알림함 표시.


### T-04. 공통 강의 분반 담당 강사 변경·진행 중 평가 인계

1. 관리자는 담당 강사의 활동 중단·지연·정지 시 분반 관리에서 **분반 담당 강사를 같은 세부 취미 권한이 있는 다른 강사로 변경**한다(D-59, 구 D-40 수강 건 이동 대체). 수강생은 분반을 옮기지 않는다.
2. 강의 콘텐츠는 여전히 동일하고 학습자의 수강 회차·3차시 진도·평가 상태는 유지한다.
3. **평가 대기/진행 중의 공식 피드백 초안은 새 담당자에게 승계**하며, 기존 `평가 시작` 잠금과 기존 **7일 마감**을 유지한다. 이전 강사는 즉시 해당 평가 수정 권한을 잃는다.
4. 이미 평가 완료된 공식 피드백은 원 작성자·작성일을 유지하며 새 담당은 읽기 전용으로 확인한다(Q-04).
5. 담당 변경 자체는 정원 반환 사유가 아니며 기한을 새 168시간으로 시작하지 않는다. 기존 담당자의 기한 초과 이력은 소급 삭제하지 않는다. 새 담당 강사의 경고 판정에는 **인계 후 유예 시간**을 적용한다(D-43, 수치 미정·P2).
6. 강사 합산 30건 검사가 없으므로 이동 대상 만석 문제(U11)는 발생하지 않는다(D-52·D-59). 개인 제작 강의 관련 처리는 전체 [확장](D-45)이다.

### T-05. 강사 계정 비활성화·탈퇴·콘텐츠 이용 종료

**정상 시나리오**

1. 강사가 비활성화 또는 활동 종료되더라도 운영 측이 보유한 자체 영상 제공이 가능한 강의는 정상 제공한다.
2. 기존 수강자 상태·진도·수료·배지를 강사의 계정 종료만으로 취소하지 않는다.
3. 과거 강사 공식 피드백의 작성자 이력은 유지한다.
4. 관리자가 새 담당자를 지정해 미작성 피드백을 인계한다.
5. 자체 업로드 영상의 제공 종료가 예정되면 관리자가 종료일 최소 한 달 전에 공지한다.

**예외 시나리오**

- 예정 종료일까지는 기존 수강자 학습/과제 제출을 각자의 30일 수강기간 안에서 허용하고, 종료일부터 신규 신청을 중단한다. 영상 접근은 **수강 30일 이내 또는 수료자**(D-42)이며 구 '60% 완료자 제출·재제출 허용' 예외는 대체되었다.
- 대체 영상이 없어 취미의 필수 수준별 강의를 모두 제공할 수 없게 되면 취미 자체를 준비 중으로 전환한다.
- [확정 D-27] **강사 완전 탈퇴**의 경우 기존 공식 피드백 본문과 작성일을 학습 기록으로 보존하되 작성자 표시는 ‘활동 종료 강사’로 바꾸고 로그인·실명·이메일·계정 링크를 제거한다. 단순 비활성화·담당 해제는 기존 작성자 표시를 유지한다.

**추가 결정:** [확정] 외부 영상 없음, 직접 업로드 영상, 강사 계정 종료와 수강 기록의 독립성, 한 달 사전 공지.


### T-06. 피드백 기한 초과·관리자 경고·담당 자격 정지 [신규 확정]

**정상 시나리오**

1. 유효 최종 과제가 제출되면 담당 강사의 피드백 기한이 **제출 시각 + 7×24시간**으로 정해진다.
2. 기한까지 공식 피드백이 없으면 담당 강사에게 알림이 가고, 해당 제출물이 강사 제출물 목록의 **0순위(최상단)**로 고정된다.
3. **마감 시각을 실제로 지난** 미작성 제출물은 강사 화면에서 즉시 0순위 대상이다. **기한 초과 후 작성 완료된 건도 관리자 경고 대상에서 빠지지 않는다.** 관리자 화면은 기한 초과한 건을 **담당 강사+마감이 속한 KST 날짜**로 묶으며, 관리자가 확인하면 **묶음당 경고 1회**만 부여한다. 같은 제출물을 다음 날 다시 경고하지 않는다(D-19).
4. 경고는 관리자 확인 날짜와 관계없이 **마감일의 KST 분기**에 귀속된다. **9월 30일 마감 건을 10월 1일에 확인해도 3분기 경고**다(D-19). 분기별 누적은 구분하며, KST 분기 첫날 00:00 초기화 원칙을 유지한다.
5. 같은 분기 안에 경고가 3회 누적되면 관리자는 해당 강사의 **강의 담당 자격을 2주(14×24시간)간 정지**한다. 강의 자체는 학습자에게 계속 제공된다.
6. 정지 기간의 미작성 피드백은 적격 전문강사에게 인계한다. [확장] 준강사는 질문/실습 보조만 가능하며 **공식 피드백·평가 인계 대상이 아니다**. [MVP] 같은 세부 취미 권한이 있고 담당 자격이 유효한 다른 전문 강사로 관리자가 **분반 담당을 변경**한다(D-59). **적격 강사가 없으면 관리자 공백 대기 목록에 두고 영향받는 학습자에게 운영용 이메일로 수동 안내(Q-03a B)**한다. **기존 제출/정식 재제출 시각에서 시작된 168시간 평가 기한과 작성 중인 초안·수정 잠금을 그대로 승계**한다. 담당자 재배정으로 마감을 초기화하지 않는다. 기존 지연 경고의 귀속은 이미 발생한 사실을 소급 삭제하지 않고 기존 P2 운영 정책에 따라 구분한다.
7. 정지 중에도 취미 권한은 유지되므로 공개 작품 일반 댓글은 쓸 수 있다.
8. 정지가 끝나도 담당에 자동 복귀하지 않는다. 관리자에게 정지 종료 알림이 가고 관리자가 재배정한다.

**예외 시나리오**

- 기한 초과 이력은 단순 수정·담당 재배정·학습자 탈퇴 후에도 자동 삭제하지 않는다. 관리자 공개 작품 숨김은 피드백 책임 면제 사유가 아니다(Q-02). 담당 공백은 관리자 대기 목록에서 관리하되 7일 평가 마감은 제출/정식 재제출부터 계속 진행한다. **수료 승인된 과제의 작성자 직접 삭제 후처리(D-32)는 미정이며 면제 조건으로 임의 확정하지 않는다.** 관리자 무효→수료 철회·복구 제도는 폐기됐다.
- **[PDF 우선]** 담당 공백 중에도 기간 내 제출된 과제의 **최초 제출/정식 재제출 기준 고정 168시간 평가 의무**는 유지한다. **[확정 D-43]** 기한은 고정하되, 담당 변경으로 새로 담당하게 된 강사에게는 **인계 후 유예 시간 동안 경고 판정을 하지 않고**, 인계 이전에 이미 발생한 지연은 이전 담당자에게 귀속한다(D-28 보존). 유예 시간 수치는 P2 구현 시 결정.
- **관리자 작품 숨김·복구는 피드백 기한을 중단하거나 새 168시간을 부여하지 않는다(Q-02).** 과거의 강제 비공개 해제 시 기한 재설정 제안은 후속 제재 기능을 설계할 때만 검토한다.
- **평가 시작 전** 학습자가 과제를 단순 수정·임시저장해도 **마감 시각은 바뀌지 않는다**. 반려 후 **정식 재제출 클릭**에 한해 새로운 7×24시간 기한을 계산한다. 이미 발생한 지연·경고 사실은 소급 취소하지 않는다.
- 정상 과제 수정 뒤 재확인 알림은 새 피드백 의무가 아니므로 기한·경고 대상이 아니다.
- [확장 D-33] 신고 처리 중에도 기한은 진행한다(D-03).
- 부여된 경고는 대상 제출물이 탈퇴·30일 파기로 삭제돼도 분기 누적에서 빠지지 않는다. 경고 기록에는 학습자·작품 정보를 남기지 않는다(D-06).
- 시스템은 경고를 자동 부여하지 않고 기한 초과 목록만 관리자에게 보여준다.
- 피드백 지연·경고·정지가 **이미 확정된 수료를 자동 취소하지는 않는다**. 다만 미평가 상태인 학습자는 **담당 전문강사의 필수 피드백과 수료 승인 전까지 수료되지 않는다**.

**추가 결정:** [확정] 제출 시각 기준 기산, 0순위 표시, 관리자 확인 후 경고, 상황 1번당 1회, 분기 초기화, 3회 누적 시 담당 자격 2주(14×24시간) 정지, 면제 대상, 기한 초과일(KST 하루) 단위 묶음·제출물당 1회, KST 분기 초기화, 정지 중 공개 댓글 허용, 자동 복귀 없음. 제공 종료 강의에도 동일 적용.

## 3. 관리자 ADMIN 시나리오

### A-01. 대분류·세부 취미 등록

**정상 시나리오**

1. 관리자가 대분류 또는 세부 취미를 등록한다.
2. 이름·소개·이미지 등 제공 가능한 정보를 입력한다.
3. 상태를 선택하지 않고 저장하면 비공개 초안으로 생성한다.
4. 준비 중 '공예'에는 목공·가죽공예·도자기·반지공예의 이름·소개·썸네일을 등록해 사용자에게 노출한다.
5. 비공개 '사진·영상'에는 사진 촬영·영상 편집의 이름/세부 분류를 등록하고 소개·이미지는 관리자 화면에서 편집할 수 있다.
6. 운영 중으로 전환하려면 하위 공개 가능한 취미 1개 이상, 세부 취미는 입문·중급·고급 강의 각 1개 이상 조건을 확인한다. MVP에서 신규 강의·영상은 운영 측이 DB 입력으로 추가하고 관리자는 검수·승인만 한다(D-01).
7. 공통 카테고리 화면에 데이터가 추가되어 신규 페이지 개발 없이 목록을 제공한다.

**예외 시나리오**

- 조건 미충족 비공개 초안을 수강 가능 상태로 자동 전환하지 않는다.
- 비공개 '사진·영상'의 목록·수정 권한은 MVP에서 관리자에게만 제공한다.
- 강사/학습자의 비공개 직접 접근을 거부한다.

**추가 결정:** [확정] 미선택 상태=비공개 초안, 공예 하위 4개 소개·썸네일, 사진·영상 하위 2개 및 관리자 전용 수정.


### A-02. 카테고리 수정·비공개·삭제·복구

**정상 시나리오**

1. 관리자가 기존 대분류나 세부 취미의 설명·이름·상태를 수정한다.
2. 카테고리 이름 변경 시 내부 식별자·URL·연결된 학습 데이터는 유지한다.
3. 상위 대분류를 비공개 처리하면 일반 사용자에게 하위 취미도 숨긴다.
4. 삭제된 카테고리는 일반 사용자에게 보이지 않고 신규 신청을 차단하되 관련 학습·수료 기록은 보존한다.
5. 복구 시 이전 강의를 자동으로 다시 공개하지 않는다.
6. 대분류를 재공개할 때 하위 취미의 상태는 관리자가 다시 설정한다.

**예외 시나리오**

- 카테고리 삭제를 학습 기록 삭제와 동일한 처리로 취급하지 않는다.
- 상태를 복구했다고 비공개 또는 제재된 강의가 자동 수강 가능해지지 않는다.

**추가 결정:** [확정] 이름 변경 시 식별자·학습 기록 유지, 삭제·복구가 학습·수료 기록과 강의 공개 상태를 바꾸지 않음, 대분류 재공개 시 하위 상태 관리자 재설정(05 §3).


### A-03. 강사 계정 생성·취미 권한 부여/회수

**정상 시나리오**

1. 관리자는 전문 강사의 별도 INSTRUCTOR 계정을 직접 만들어 제공한다.
2. 활동할 세부 취미 권한을 부여하고 개별 강의 담당자로 배정할 수 있다.
3. 강사 한 명이 여러 취미 권한·여러 강의를 담당할 수 있다.
4. [확장] 마스터 배지 학습자의 준강사 자격 신청을 관리자가 검토·승인하는 기능을 향후 제공한다.
5. [확장] 승인 시 기존 USER 계정에 준강사 권한을 추가하되 학습자 활동을 유지한다.
6. [확장] 전문 강사의 보조·공백기 대리 활동은 해당 기능의 권한·기간 규칙을 정한 이후 도입한다.

**예외 시나리오**

- 준강사는 기존 회원 권한을 잃지 않으며 관리자 생성 강사 계정 방식과 구별한다.
- 배지를 갖고 있다고 승인 없이 자동으로 준강사 권한을 받는 것은 아니다.
- 이번 MVP는 준강사 역할·메뉴 설계안만 남기며 실제 신청/승인/대리/비공개 과제 접근 기능을 제공하지 않는다.
- 확장 시 공식 피드백·비공개 접근 권한 및 마스터 배지 무효/회수 시 준강사 자격은 별도 결정한다.
- 마지막 관리자 계정 비활성화·삭제 금지([확정 D-08]).

**추가 결정:** [확장 기획 확정] 마스터 배지→신청→관리자 승인→기존 USER에 준강사 권한 추가. [MVP 제외] 실행 기능은 제외, 설계안만 보존. [확장 미정] 공식 피드백 대행/배지 철회 처리.


### A-04. 공통 강의 강사 분반·정원·평가 책임 배정

**정상:** 관리자는 1개 공통 강의(시드 데이터)의 동일 영상·차시·최종 과제에 여러 **분반을 생성**하고, 분반별로 전문강사 1명과 **정원(1~30)**을 지정한다. 강사 합산 30건은 검사하지 않는다(D-52). 학습자는 신청·자동 확정 과정에서 남은 자리가 가장 큰 분반으로 배정된다. 관리자는 강사 통계(P0, 분반별 현재 숫자)와 평가 현황을 확인한다.

**예외:** 강사 교체 시 관리자는 **분반 담당 강사를 변경**하며(D-59) 진행 중인 과제의 피드백 초안·수정 잠금·평가 기한은 **그대로 승계**한다. 이미 작성 완료된 피드백은 후임 읽기 전용. 강사 변경 자체로 정원·7일 마감 초기화 금지. 정원은 현재 활성 수강 수 아래로 줄일 수 없고, 늘리면 늘어난 자리만큼 대기 1순위부터 자동 확정한다. 개인 제작 강의는 전체 [확장](D-45).

### A-05. 강의·영상 준비 및 관리자 검수·승인

**정상 시나리오**

1. 운영 세부 취미 3개×수준 3개=9강의를 준비한다.
2. 운영 측이 강의·차시·자체 영상 파일을 준비하여 DB 입력으로 연결한다(**강의당 3차시(총 27차시), 영상 파일 총수 미정**, D-01).
3. 관리자가 영상/목표/성취 기준/최종 실습을 검수·승인한 후 공개한다.
4. 종료 예정 영상이 있으면 제공 종료 최소 한 달(종료 시각 − 30×24시간, D-07) 전에 공지한다.
5. 종료일부터 신규 신청을 중단한다. 영상 접근은 **수강 30일 이내 또는 수료자**만 가능하다(D-42): 이미 수료 승인된 사용자는 무제한 재시청, 미수료자는 **본인 30일 수강기간 안에서만** 시청·신규 제출·정식 재제출할 수 있다. 구 '60% 완료자 예외'(D-05·R-05)는 폐기·대체되었다. 수료 후 직접 삭제 후처리(D-32)는 미정이다. **관리자 무효 후 재제출 제도는 폐기**.
6. 수준별 강의가 빠져 최소 운영 조건을 충족할 수 없으면 해당 취미를 준비 중으로 바꾼다.
7. [D-20] **준비 중 전환은 신규 신청 제한**이며, 이미 해당 강의를 수강한 학습자의 **나의 학습 기록과 허용된 재시청·과제 제출/수정/재제출 동선은 유지**한다.

**예외 시나리오**

- YouTube 임베드와 외부 영상은 사용하지 않는다.
- 영상 파일 업로드 실패/손상/재생 실패 시 정상 공개 상태로 전환하지 않는다.
- 강사 직접 강의·영상 등록 UI와 **관리자 강의·영상 등록 화면**은 확장으로 둔다. MVP의 강의·영상 추가는 DB 입력 후 관리자 검수·승인(D-01).
- [개발 검증] 영상 보관·스트리밍·진도 기록 및 세션 1시간/영상 재생 중 연장 기능.

**추가 결정:** [확정 D-26] 운영 측 DB 입력 후 **관리자 검수·공개 승인**, 종료 1개월 전 공지, 초기 9강의·27차시. **관리자 영상·강의 업로드 화면은 확장**. [개발 회의] 영상 저장·재생/세션 기술.


### A-06. 관리자 공개 작품 숨김·복구 [Q-01·Q-02 확정]

**정상 시나리오 (MVP)**

1. 관리자는 **공개된 최종 과제 및 공개 일반 작품**만 확인해 게시판 노출을 숨길 수 있다. 관리자 댓글 단독 조치·직접 삭제는 제공하지 않는다.
2. 숨김 사유를 작성자 전용 서비스 화면(U-S16)에 표시한다. 숨김·복구 결과는 **사이트 알림**으로만 알린다(이메일 없음, D-57). 서비스 내 사유 표시만으로 이메일 발송이 완료된 것으로 간주하지 않는다. 신고 접수·처리 화면은 없다.
3. 숨긴 작품은 일반 사용자에게 목록·상세·원본 URL로 제공되지 않는다. 그러나 **작성자·현재 담당 강사는 해당 최종 과제 원본과 공식 피드백에 계속 접근**한다.
4. 숨김은 공개 노출만 제한하므로 **수료일·수준/마스터 배지·강사의 공식 피드백 책임/기한·기존 피드백을 유지**한다.
5. 작성자는 숨김 중 정상적으로 작품을 수정할 수 있으나 관리자 숨김을 스스로 해제할 수 없다. **숨김 해제는 관리자만** 한다.
6. 관리자가 숨김을 복구해도 작성자가 개인 비공개를 선택했다면 작품은 일반 공개되지 않는다.

**예외 시나리오**

- 숨김 전부터 열린 화면에서도 일반 이용자의 상세·이미지 직접 접근을 차단한다.
- 관리자 숨김 여부와 작성자의 공개 선택은 별도 판단한다. 작성자 설정 변경·수정으로 관리자 숨김을 우회할 수 없다.
- 관리자 과제 무효→수료 철회·배지 유예·오판 복구 절차는 2026-10-30 PDF에 따라 **폐기**되어 숨김과도 연동하지 않는다. 신고 기능만 별도 [확장]이다.
- 강제 숨김에 대한 공식 이의제기 UI는 확장이다.

**추가 결정:** [확정 Q-01/Q-02] 공개 작품 숨김·복구만 관리, 작성자·담당 강사 접근 보존, 학습·피드백 책임 불변. [확장] 무효·신고·이의제기.

### A-07. [폐기 이력] 관리자 과제 무효·수료 철회·유예·오판 정정

관리자 과제 무효로 인한 **수료 철회·14일 배지 유예·30일 보완기간·무효 오판 복구**는 2026-10-30 최종 PDF에 따라 폐기한다. 일반적인 **담당 전문강사의 평가 반려 및 반려 오판 정정**과 다르다. A-07은 과거 결정의 ID 추적용이며 현행 개발 기능이 아니다.

### A-08. 강사 피드백 신고 처리 [확장 D-33]

> MVP 미포함(D-33). 신고 기능 도입 시의 흐름으로 보존한다.

**정상 시나리오**

1. 관리자가 강사 공식 피드백에 대한 신고를 검토한다.
2. 문제없음·숨김·강사 수정 요청 중 조치한다. **수정 요청하면 해당 피드백은 확인 완료 전까지 숨김** 처리한다(D-21).
3. 조치 결과는 신고 관련 이용자에게 이메일로 통지한다.
4. 필요한 경우에만 담당 강사에게 추가 운영 안내를 전달한다.
5. 수정 요청에 따라 강사가 피드백을 고쳐도 자동 재공개하지 않는다. **관리자가 수정 결과를 최종 확인·승인했을 때만 재노출**한다(D-21).

**예외 시나리오**

- 관리자가 강사의 피드백 원문을 직접 수정하지 않는다.
- 숨김 처리한 피드백과 추천 복습은 일반 목록에서도 숨긴다.
- 숨김·수정 요청 상태의 피드백은 개인 성장 기록의 ‘참고한 피드백’ 연결을 통해서도 원문이 노출되지 않는다.
- 학습자 정식 이의제기 신청 및 신고 결과 재검토 UI는 확장이다.

**추가 결정:** [확정] 관리자 신고 조치 이메일 통지, 관리자 직접 피드백 원문 수정 불가.


### A-09. 강사 이용 종료·영상 종료 한 달 사전 공지·담당 재배정

**정상 시나리오**

1. 강사 비활성화가 발생해도 자체 영상의 제공이 유효하다면 강의·진도·수료 이력을 유지한다.
2. 관리자가 분반 담당 강사를 다른 적격 강사로 변경하여 미작성 피드백을 인계한다(D-59).
3. 적격 강사가 없으면 관리자가 서비스 밖 운영용 이메일로 수동 안내(Q-03a 방식 A, 시스템 메일 알림 아님)한다.
4. 영상 제공 종료 예정일이 정해지면 최소 한 달 전에 공지한다.
5. 종료일 전까지 기존 수강자의 학습과 실습 제출을 각자의 30일 수강기간 안에서 허용한다.
6. 종료일부터 해당 강의의 신규 신청을 중단한다. 영상 접근은 **수강 30일 이내 또는 수료자**만 가능하다(D-42). 이미 수료 승인된 사용자의 무제한 재시청은 유지하고, 미수료 사용자의 시청·신규 제출·정식 재제출은 **개별 30일 수강기간 내에만** 허용한다. 수료 후 직접 삭제 후처리(D-32)는 미정이다. **관리자 무효 후 재제출 제도는 폐기**.
7. 대체 영상이 없어서 입문·중급·고급 중 필수 수준을 제공할 수 없으면 취미 자체를 준비 중으로 바꾼다. 그 결과 대분류에 운영 중 하위 취미가 없어지면 관리자 화면에 대분류 상태 재설정 필요가 표시되고 관리자가 변경한다(D-31).
8. [D-20] 취미가 준비 중이 돼도 기존 학습자는 **나의 학습 현황에서 이미 허용된 강의·기록·과제에 접근**한다. 신규 수강만 제한한다.

**예외 시나리오**

- 영상 종료·준비 중 전환은 이미 정상 수료한 학습자의 수료·배지·학습 이력을 철회하지 않는다.
- 제공 종료된 강의도 담당 강사 배정과 피드백 책임·경고 제도는 유지한다.
- 예정 없이 자체 영상이 재생 불가하게 되는 운영 장애는 '외부 영상 예고 없는 삭제'와 구별한다. 복구 전 임시 조치는 별도 상세 결정을 따른다.
- 강사 풀 조정과 강사 책임 강화 및 개별 강사 전용 콘텐츠 상세 설정은 확장 기능이다.

**추가 결정:** [확정] 종료 한 달 전 공지, 종료일부터 신규 신청·60% 미달자 시청 중단, 취미 준비 중 상태 전환.


### A-10. [폐기 이력] 무효 자료 보관·30일 파기

폐기된 관리자 무효·수료 철회·보완기간과 연결된 별도 보관 정책은 현행으로 적용하지 않는다. **탈퇴 개인정보 삭제·재가입 제한 확인값 30일 보유**는 서로 다른 기존 정책으로 유지한다.

### A-11. 공통 강의 대기열 조회·정원·강사 P0 통계 [신규 · D-53·D-58·D-59]

1. 관리자는 **강의별 단일 대기열(FIFO)**에서 대기 순서·대기 신청 시각과 분반별 남은 자리를 **조회만** 한다(순번 변경·수동 확정 없음).
2. 분반에 자리가 생기면 시스템이 **대기 1순위를 즉시 수강 확정**하고 사이트 알림을 보낸다. 관리자 화면에는 최근 자동 확정 내역이 보인다.
3. 분반 정원(1~30) 초과만 차단한다. 강사 합산 30건 검사는 없다(D-52).
4. 관리자/강사 본인에게만 **분반별 수강 중·수료·반려·평가 대기 수(현재 숫자)**를 표시한다(D-58). 학습자에게는 공개하지 않는다.
5. 월별 추이·수료율·평균 진도율·과거 실적은 후속이다.

7. [SYSTEM] USER B의 답글과 USER B의 작성자 정보를 원래대로 유지한다.
8. [확장 D-33] [SYSTEM] 완료된 일반 신고는 삭제하고 진행 중 신고 및 필요한 증거·최소 신고자 신원은 처리 완료까지 예외적으로 보존한다.
9. [확장 D-33] [ADMIN] 신고 처리를 완료하면 법적 보존 의무를 확인한 후 예외 보존 자료를 삭제한다.

### X-07. [확장] 준강사 학습 질문·실습 보조

1. 향후 준강사 등록/승인은 [확장]으로 검토한다.
2. 준강사는 **질문 응답 및 실습 보조만 가능**하며 **공식 최종 과제 평가·수료 승인·반려를 수행하지 않는다**(Q30=A).
3. 전문강사 공백 시 준강사에게 공식 평가를 맡기지 않는다. 전문강사 임시 지정은 개인 제작 강사 이탈 확장 Q23에 따르며 관리자 직접 평가 권한도 부여하지 않는다.

### X-08. 동일 계정 다른 기기 로그인과 1시간 세션
1. [USER] PC A에서 아이디로 로그인한다.
2. [USER] PC B에서 같은 아이디로 로그인에 성공한다.
3. [SYSTEM] PC A의 기존 로그인 상태를 종료하고, 인증이 필요한 다음 요청을 거부한다.
4. [USER] PC B의 영상 학습 화면에서는 재생·일시정지 중 정해진 범위에서 로그인 상태가 유지된다.
5. [SYSTEM] 영상 학습 화면 밖에서는 마지막 요청 후 1시간 유휴 규칙을 적용한다.
6. [USER] 세션이 만료되면 홈으로 이동한다.
7. [확정] 브라우저를 종료하고 재접속하면 다시 로그인한다. 내부 세션 만료 방법은 `DEV_REVIEW.md`에서 검토한다.

### X-09. 평가 전 수정·일반 작품 삭제·관리자 숨김 [기존 P1/P2 유지]

1. [USER] 수강기간 내 최종 과제를 제출해 **평가 대기**에 들어간다. 이때는 수료가 아니다.
2. [USER] 담당 강사가 `평가 시작`을 누르기 전에는 제출물을 수정/임시저장할 수 있으며, 기한은 **기존 제출+7일** 그대로다. 시작 이후에는 잠금.
3. [INSTRUCTOR] 수료 승인 시 필수 피드백을 완성하고 강의 수료·배지 발급. 반려 시 사유 작성·기간 안 정식 재제출 허용.
4. [USER] 일반 작품을 여러 개 등록하거나 삭제할 수 있으며 이것만으로 수료 상태가 바뀌지는 않는다(FR-027/050의 기존 등급 유지).
5. [ADMIN] 공개 최종 과제/일반 작품을 숨김·복구할 수 있지만 **담당 강사 평가·수료 상태/기한 불변**.
6. [미정] **수료 승인된 최종 과제의 작성자 직접 삭제와 승인 후 수정**은 후속 수료·피드백 효과를 미확정으로 둔다. 구 수료 철회·유예 흐름은 폐기.

### X-10. 신고 중인 1:1 문의 탈퇴·삭제 분기 [확장 D-33]

> **[MVP 실제 흐름]** 학습자가 탈퇴하면 주고받은 1:1 문의 스레드는 진행 중 신고 여부와 무관하게 즉시 전체 영구 삭제된다.
> **[확장 D-33 참고]** 향후 신고 기능 도입 시에만 진행 중 신고 스레드를 임시 보존한다(아래 1~6번).
1. [USER] 강사와 텍스트 문의를 주고받은 뒤 문의 답변을 신고한다.
2. [ADMIN] 신고를 접수하고 검토 중인 상태로 둔다.
3. [USER] 탈퇴하면 시스템은 계정 정보 및 일반 학습·작품 데이터를 삭제한다.
4. [SYSTEM] **신고가 진행 중인 해당 문의 스레드만** 비공개로 잠시 보존하고, 일반 문의 스레드는 삭제한다.
5. [ADMIN] 신고를 처리하면 보존 의무 유무를 확인하고 예외 보존이 필요하지 않은 스레드·증거를 삭제한다.
6. [분기] 신고 없이 탈퇴하면 문의 스레드 전체를 즉시 삭제한다.

### X-11. 30일 수강 만료·평가 지연 예외 [신규]

1. 11월 1일 수강 확정자 A가 11월 29일 정식 재제출하면 **7일 새 평가 기한**이 시작되어 수강 30일 종료 후에도 강사는 결과를 확정해야 하고 그동안 정원을 계속 점유한다.
2. 30일 후 최종 반려 시 A는 같은 회차에서 재제출 불가하고 **같은 강의 재신청도 불가**(D-55). 자리가 반환되어 대기 1순위가 자동 확정된다. 강사는 반려 사유를 기록한다.
3. [확장 D-37] 반려 결과를 사후에 수료 승인으로 바꾸는 오반려 정정은 MVP에서 제공하지 않는다. 확장 도입 시에도 이미 반환한 자리·자동 확정된 다음 학습자는 되돌리지 않는 원칙을 유지한다.
4. 재신청 불가(D-55)로 새 회차가 없어 이전 진도·과제 삭제는 발생하지 않는다. 강사 통계는 현재 숫자만 표시한다(D-58).
5. **[보류 D-55]** D-36(새 회차 확정 순간 삭제)·D-44(이전 시도 보관)는 재신청을 다시 허용할 때 재검토한다. 관리자 감사 이력(U02)만 미정이다.

## 7. 확장 전용 구체 시나리오 [MVP 미포함]

아래 E-01~E-03은 구체적인 후속 시나리오 초안이며 실제 운영 세부는 미정이다. 준강사 확장은 본문의 **X-07**을 참고한다.

### E-01. [확장 예정] 챌린지 참여·진행·완주

**정상 시나리오(추천 설계)**

1. 로그인한 학습자가 7일 또는 30일 취미 챌린지를 선택한다.
2. 취미·목표·진행 기간을 확인하고 참여한다.
3. 실제 실습을 일반 작품 또는 개인 실습일지로 기록한다.
4. 시스템이 기간 내 유효 인증 횟수와 진행 상태를 계산한다.
5. 조건 충족 시 일반 수료 배지와 구별되는 완주 배지를 발급한다.
6. 완주 기록과 시작/마지막 결과물이 개인 성장 타임라인에 연결된다.

**예외 시나리오(추천 설계)**

- 같은 작품 또는 하루 중복 등록을 여러 날 인증으로 처리하지 않는다.
- 공개 작품 등록은 필수가 아니며 개인의 기본 비공개 원칙을 지킨다.
- 무효·삭제된 기록, 중도 포기 또는 연속 참여 실패 처리 방식은 확장 정책에서 정의한다.

**추가 결정:** [미정] 완주 기준, 일별 인증 한도, 강사/관리자 챌린지 개설 권한, 배지 취소 규정.


### E-02. [후속 확장] 신규 유료 강의 신청

**정상 시나리오(추천 설계)**

1. 학습자는 기존 학습/성장 기록을 유지한 채 추가 프리미엄 강의를 탐색한다.
2. 선택 강의가 유료라면 가격·이용 조건을 확인한다.
3. 결제 또는 유효 할인권 적용을 거친 뒤 기존 수강 신청·진도·수료 흐름으로 진입한다.

**예외 시나리오(추천 설계)**

- 결제가 실패하면 유료 접근 권한을 부여하지 않는다.
- 기존 무료 수강자/수료자의 이전 학습 기록을 소급 삭제하지 않는다.

**추가 결정:** [미정] 구독/강의당 구매, 결제·취소, 할인 적용 범위.


### E-03. [후속 확장] 활동 코인 적립·쿠폰 교환

**정상 시나리오(추천 설계)**

1. 시스템이 중복 없이 확인한 실습 성취 또는 챌린지 완주에 코인을 적립한다.
2. 학습자는 코인 내역을 확인하고 허용된 할인 쿠폰과 교환한다.
3. 유효한 쿠폰을 사용해 새로운 프리미엄 강의의 결제 금액을 할인받는다.

**예외 시나리오(추천 설계)**

- 같은 활동 중복 보상·허위 실습·무효 처리 등은 규칙에 따라 적립을 제한 또는 정정한다.
- 현금 출금·사용자 간 이전은 허용하지 않는 방향으로 제안한다.

**추가 결정:** [미정] 발행·차감·만료·환불·부정 사용 정책.
