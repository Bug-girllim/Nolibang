# PRD — Atelier de loisirs (놀이방)

> **[2026-11-05 MVP 단순화 결정 D-51~D-59 · 이 문서의 모든 앞선 기준보다 우선]** ① 강사 계정은 관리자가 **임시 비밀번호로 즉시 생성**(메일 설정 링크 없음, 첫 로그인 시 비밀번호 변경, D-51·FR-012) ② 공통 강의 분반은 여러 개·정원 1~30 유지, 배정은 **남은 자리가 가장 큰 분반** 한 줄 규칙, **강사 합산 30건 검사 삭제**(D-52·FR-052) ③ **단일 대기열(FIFO)** 유지, 자리가 나면 **1순위를 즉시 수강 확정 + 사이트 알림**, 초대·수락·48시간 단계 없음(D-53·FR-053) ④ 수강 취소 → 자리 반환 → **대기 1순위 자동 확정**(D-54·E6) ⑤ 같은 강의는 **수료(D-35)뿐 아니라 취소·만료한 강의도 이번에는 재신청 불가**(D-55·FR-055 P1) — 재수강 기록 삭제(D-36)·이전 시도 보관(D-44·FR-056)은 대상이 없어 보류 ⑥ 평가는 **시작(잠금) → 초안 → 승인/반려**, 시작 취소, 마감 임박·기한 초과 경고 유지(D-56·FR-023·030·031) ⑦ 알림은 **사이트 알림만**: 평가 결과(승인/반려)·대기→자동 확정·수료, **이메일 알림 없음**(D-57·FR-035) ⑧ 강사 통계는 **현재 숫자만**: 분반별 수강 중·수료·반려·평가 대기 수(D-58·FR-051) ⑨ 관리자 MVP는 **강사 계정·분반(생성·담당·정원)·대기열 조회·관리자 홈**, 카테고리·강의는 **시드 데이터**(D-59). 결정 상세는 `05-policy.md` §14. 아래 본문에 남은 48시간 초대·합산 30건·재수강 회차·월별 통계 문구는 **결정 이력**으로만 본다.

## 1. 제품 한 줄 정의

영상 중심의 취미 강의를 **3차시 학습·과제 제출·담당 강사의 필수 피드백과 승인**으로 수료하며, 공식 강사 피드백과 개인 성장 기록을 통해 다음 실습으로 이어지는 **실습형 취미 LMS**.

**[임시 확정 슬로건]** “강의를 보는 곳이 아니라, 취미 실력이 쌓이는 LMS.” (추후 수정 가능)

## 2. 배경과 해결하려는 문제

- 단순 영상 시청·작품 공유만으로는 사용자가 **이전 실습의 어려움·개선점·다음 실습 목표**를 이어가기 어렵다.
- 이미 시장에 작품 프로젝트·피드백·학습 경로·배지·포트폴리오가 존재한다. 새로움을 ‘최초 기능’으로 주장하지 않는다.
- 본 서비스는 **강의→실습→선택 회고→개선형 공식 피드백→추가 실습/작품 누적**을 취미별로 간단히 연결한다.
- 비교 조사: CLASS101·Skillshare·Domestika·솜씨당 + 전통 LMS Moodle·Canvas LMS + 수익화 참고 Thinkific. 확인 기능과 미확인을 구분했다. 상세 근거는 [01-problem.md](01-problem.md).

## 5. 핵심 가치·차별화 구현

1. **[MVP 확정] 성장 기록 B:** 최종 수료 과제+일반 작품을 **날짜순**으로 확인, 각 작품에 **선택적 한 줄 회고**(안내: 나아진 점·아쉬운 점). 같은 취미의 **첫 작품·최근 작품 썸네일 요약**, 일반 작품 등록 시 **최근 공식 피드백을 선택 연결 저장하고 타임라인에서 확인**(D-17). 회고 미작성 시에도 수료 가능.
2. **[MVP 확정] 피드백 B:** 강사 작성 화면에 **잘한 점/개선할 점/다음 연습**을 안내. 총 50자 이상·제출물당 공식 피드백 1개, 세 항목 각각 필수 작성 아님.
3. **[기존 MVP] 수준별 자유 선택과 수료 배지:** 입문·중급·고급/마스터 배지, 취미별 독립 학습.
4. **[MVP P2 확정] 3수준 상태 표시:** 세부 취미 상세(U-S02)에 입문·중급·고급의 내 상태(미수강/수강 중/수료·배지)를 3칸으로 표시. 별도 로드맵 화면은 만들지 않음.

## 6. 제품 핵심 흐름

**학습자:** 이메일 인증·로그인 → 취미/수준·공통 강의 선택 → `[여유]` 분반 자동 지정·수강 확정 / `[만석]` 강의별 단일 대기(FIFO) → **자리가 나면 1순위 자동 수강 확정·사이트 알림** → 수강 확정일부터 30일 → **강의 내부 3차시 각각 영상 60% 완료** → 직접 최종 과제 제출(평가 대기, 미수료) → 담당 강사 평가 시작·수정 잠금 → **공식 피드백 최소 50자 + 수료 승인** → 수료·배지·영상 무제한 다시 보기·알림함.

**반려:** 담당 전문강사가 반려 사유 입력 → 원래 수강기간 30일 안에서 횟수 제한 없이 수정·**정식 재제출**(재제출일 기준 새 7일) → 재평가. 기간 뒤 반려되면 동일 회차 재제출 불가.

**강사:** 로그인 첫 화면 담당 강의·분반 → 본인 수강생의 차시별 진도·기간·제출/평가 이력 → 평가 대기/진행/완료 탭(48시간 이하 임박·기한 초과 경고) → `평가 시작` 클릭으로 잠금 → 피드백 초안 → 승인/반려 → **강사 통계 P0(현재 숫자)**.

**관리자:** 관리자 홈 → 강사 계정 생성(임시 비밀번호)·취미 자격 → 공통 강의 분반 생성·담당·정원(1~30) → 강의별 대기열 조회 → 강사 통계·평가 운영(강사 교체 시 분반 담당 변경) → 공개 작품 숨김·복구. 카테고리·9개 강의는 시드 데이터. 개인 제작 강의는 [확장].

## 8. 구현·확장 범위

- **우선순위 변경:** 10-30에 **강사 통계 P1→P0 승격(FR-051)**, 10-31에 **분반 배정·정원(FR-052)·대기열·초대(FR-053)·30일 기간(FR-054) P0, 재신청·재수강(FR-055) P1 신설**, 이전 시도 보관(FR-056)은 등급 미정. **11-05 단순화(D-51~D-59): P등급 변경 없음, FR-011·014는 시드 데이터로 범위 제외, FR-056 보류.** 강사 LMS의 사용자·평가 화면은 확정 방향이지만 PDF에서 다른 기능까지 일괄 P0 승격하지 않았다.
- **기존 P1/P2 유지:** 게시판/일반 작품/성장 기록, 관리자 공개 작품 숨김·복구, 탈퇴·작성자 일반 작품 삭제, 기존 경고·정지·영상 제공 종료는 각각 03의 해당 등급을 따른다.
- **[확장 유지]:** 신고·**개인 제작 강의 전체**(Q21~25 이탈 대응 포함)·**강사 오반려 정정(D-37)**·10-31 UX 개선 항목, 준강사(Q30: 질문 응답·실습 보조만, 공식 평가 불가), 7일/30일 챌린지·수익화 로드맵.
- **[미정]:** U02·U10·U11과 세부 예외는 `05-policy.md` §11-1·§13에 정리했고, 정책을 선택하기 전 임의 구현하지 않는다. 특히 수료 확정된 과제의 작성자 직접 삭제에 의한 **수료 철회는 폐기**, 승인된 과제 삭제 후처리 및 승인 후 수정 범위는 별도 확정 필요.
- **기술 검토:** 스키마·동시성(자리 반환↔1순위 자동 확정)·평가 잠금·임시 비밀번호·시드 데이터·미디어 업로드는 `DEV_REVIEW.md`로 분리한다.

> **2026-10-31 FR 집계:** 현행 정의 행 총 **45개(P0 19·P1 14·P2 8·확장 3·등급 미정 1)**, NFR 9개. FR-037~039는 폐기되어 정의 행에서 제외하되 ID 이력은 03에 보존. 현재 집계와 우선순위 정본은 `03-requirements.md`.

> **운영 리스크(D-49):** 강사 1명당 공통 활성 수강 30건이며 평가 완료까지 자리를 점유하므로 **강사 수가 곧 서비스 수용량**이다. 평가가 늦어지면 대기열 전체가 멈출 수 있어, 시연·운영 시 강사 수와 평가 속도를 함께 관리한다.

## 9. 검수 기준

1. **[P0]** 가입/로그인, 분반·수강/3차시 완료, 과제 제출 후 미수료 평가 대기, **50자 이상 피드백+강사 승인** 후 수료·배지/알림, 역할별 접근 차단.
2. **[P0]** 강사 본인/관리자의 **강사 통계(분반별 현재 숫자)** 조회와 수강생 비공개.
3. **[P0 FR-052~054 / P1 FR-055]** 남은 자리 최대 분반 배정, 강의 단일 대기열(FIFO)·자리 반환 시 1순위 자동 확정·사이트 알림, 수강 취소→자동 확정, 분반 정원 1~30, 30일 수강기간·영상 접근·만료 후 평가, 수료·취소·만료 강의 재신청 차단, 7일 기한 고정/잠금/재제출·반려 처리.
4. **[P1/P2 조건부]** 일반 작품·댓글·성장·관리자 공개 작품 숨김·복구, 탈퇴·기존 P2 운영 기능은 각각 FR 수용 조건대로 검증.
5. **[확장/폐기 제외]** 개인 제작 강의 전체·준강사·신고·오반려 정정은 확장. 수료 철회·14일/30일 유예·무효 재수료 보완은 **폐기**로 구현/시연하지 않는다.

## 정식 공개 전 필수 확인

현재 MVP는 팀 시연·제한 테스트를 대상으로 한다. **실제 일반 사용자에게 공개하기 전** 인증·권한·파일/개인정보·커뮤니티 안전·운영 대응 등을 `00-backlog.md` §11에 따라 점검해야 하며, 미충족 시 공개 범위를 제한하거나 정식 공개를 보류한다. 새로운 보안·신고 UI를 MVP에 자동 포함하지 않는다.
