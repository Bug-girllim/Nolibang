# 05. 서비스 운영 정책 — 확정 기준집

> **[2026-11-05 MVP 단순화 결정 D-51~D-59 · 이 문서의 모든 앞선 기준보다 우선]** ① 강사 계정은 관리자가 **임시 비밀번호로 즉시 생성**(메일 설정 링크 없음, 첫 로그인 시 비밀번호 변경, D-51·FR-012) ② 공통 강의 분반은 여러 개·정원 1~30 유지, 배정은 **남은 자리가 가장 큰 분반** 한 줄 규칙, **강사 합산 30건 검사 삭제**(D-52·FR-052) ③ **단일 대기열(FIFO)** 유지, 자리가 나면 **1순위를 즉시 수강 확정 + 사이트 알림**, 초대·수락·48시간 단계 없음(D-53·FR-053) ④ 수강 취소 → 자리 반환 → **대기 1순위 자동 확정**(D-54·E6) ⑤ 같은 강의는 **수료(D-35)뿐 아니라 취소·만료한 강의도 이번에는 재신청 불가**(D-55·FR-055 P1) — 재수강 기록 삭제(D-36)·이전 시도 보관(D-44·FR-056)은 대상이 없어 보류 ⑥ 평가는 **시작(잠금) → 초안 → 승인/반려**, 시작 취소, 마감 임박·기한 초과 경고 유지(D-56·FR-023·030·031) ⑦ 알림은 **사이트 알림만**: 평가 결과(승인/반려)·대기→자동 확정·수료, **이메일 알림 없음**(D-57·FR-035) ⑧ 강사 통계는 **현재 숫자만**: 분반별 수강 중·수료·반려·평가 대기 수(D-58·FR-051) ⑨ 관리자 MVP는 **강사 계정·분반(생성·담당·정원)·대기열 조회·관리자 홈**, 카테고리·강의는 **시드 데이터**(D-59). 결정 상세는 `05-policy.md` §14. 아래 본문에 남은 48시간 초대·합산 30건·재수강 회차·월별 통계 문구는 **결정 이력**으로만 본다.

## 1. 역할과 인가

| 역할 | 계정 출처 | 핵심 권한 | 제한 |
| --- | --- | --- | --- |
| **USER** | 본인 회원가입 | 탐색/신청/학습/과제/일반 작품/댓글/학습 기록(신고는 확장 D-33) | 타인의 비공개 제출물·관리자 영역 불가 |
| **INSTRUCTOR** | 관리자가 **전문 강사 계정 별도 발급** | 해당 취미 권한의 공개 댓글, 배정된 강의의 공식 피드백·작성자 비공개 제출물 열람 | 세부 취미 권한만으로 타 강의 비공개 과제 열람 불가 |
| **ADMIN** | 운영자 관리 계정 | 카테고리·강사·담당·영상 승인, **공개 작품 숨김·복구만**(Q-01), **MVP 관리자 기능은 강사 계정(임시 비밀번호)·분반(생성·담당·정원)·대기열 조회·관리자 홈(D-59)**, 공통 강사 교체는 **분반 담당 변경** | 카테고리·강의 CRUD는 시드 데이터로 대체(D-59), 게시물 직접 삭제·댓글 단독 조치는 MVP 제외, **관리자 과제 무효·무효 정정은 폐기**, 대기열 순번 수동 변경·수동 확정 없음(D-53). 마지막 관리자 비활성화/삭제 불허 |
| **준강사 [확장]** | 마스터 배지 USER에게 추가 권한 | 학습 질문 응답·실습 보조만(Q30·D-46) | **공식 평가·수료 승인/반려·피드백 인계 불가.** 신청·승인·보조 실제 기능은 MVP 제외 |

- [확정] 강사는 여러 세부 취미 활동 권한과 여러 분반을 가질 수 있다. **공통 강의는 분반마다 담당 강사 1명**이며 하나의 공통 강의에 여러 분반·강사가 존재할 수 있다. 개인 제작 강의(제작 강사 책임)는 기능 전체가 [확장](D-45).
- [확정] 취미 권한과 특정 강의 **담당 배정은 별개**다. 공개 작품 일반 댓글은 취미 권한만으로 가능하지만 비공개 과제 열람·공식 피드백은 담당 배정 필요.
- [확정 Q-02] 관리자가 숨긴 최종 과제는 **작성자와 현재 담당 강사가 계속 열람**하며 담당 강사의 공식 피드백 책임·기한은 유지한다. 일반 회원의 직접 URL·원본 접근은 차단한다.
- [확장 D-33] 담당 강사는 담당 강의의 **작성자 비공개 최종 과제도 신고**할 수 있다. 신고만으로 과제·수료·배지 상태가 변하지 않는다. **관리자 과제 무효→수료 철회 기능은 폐기**됐으므로 신고 후 구 제재를 실행할 근거로 삼지 않는다.
- [확정 D-51 · 구 D-10 대체] 전문 강사 최초 접속: 관리자가 강사 **아이디·실명·이메일**을 입력하면 **임시 비밀번호와 함께 계정이 즉시 생성·활성화**된다 (임시 비밀번호는 시스템이 생성해 생성 직후 화면에 1회만 표시). 관리자는 임시 비밀번호를 강사에게 직접 전달하고, 강사는 **첫 로그인 시 새 비밀번호로 변경**해야 다른 화면을 이용할 수 있다. **메일 비밀번호 설정 링크는 보내지 않는다.** 강사가 비밀번호를 잊으면 관리자가 임시 비밀번호를 재발급하며, 재발급 후에도 첫 로그인 변경 규칙이 다시 적용된다. 임시 비밀번호도 평문 저장하지 않는다(NFR-02).
- [확정 D-08] 담당 강사가 해제된 뒤에는 그 강사가 과거에 작성한 공식 피드백을 수정할 수 없다(작성자 정보는 보존).
- [확정 D-27] **전문 강사 계정 완전 탈퇴**가 실제로 이뤄지면 로그인·실명·이메일 등 직접 식별정보와 계정 연결은 제거하되, 학습자에게 이미 제공한 **공식 피드백 본문·작성일은 학습 기록으로 보존**한다. 학습자 화면의 작성자 표시는 **‘활동 종료 강사’**로 바꾸고 탈퇴 계정으로 이동하는 프로필 링크는 제공하지 않는다. 단순 비활성화·담당 해제는 완전 탈퇴가 아니므로 기존 작성자 표시를 유지한다. 법적 보존·파기 의무 검증은 별도로 수행한다.
- [확장 Q30] 준강사는 학습 질문 응답·실습 보조만 수행하고 **공식 평가·수료 승인·반려 권한은 부여하지 않는다**. 기타 자격 유지 방식은 미정.

## 2. 회원가입·로그인·닉네임

- [확정] **아이디**로 로그인; 회원가입 필수: **아이디, 비밀번호, 실명, 이메일**. 이메일 인증 필수.
- [확정] 이메일은 **계정당 고유**(중복 가입 불가). 탈퇴 후 **30일이 지나야** 같은 이메일로 재가입할 수 있다. [확정 D-07] 기산 = **탈퇴 시각 + 30×24시간**.
- [확정 D-08] 비회원은 메인 홈·취미 탐색·세부 취미 소개·강의 상세 소개까지 볼 수 있다. 수강 신청·영상·작품 게시판·댓글·좋아요는 로그인이 필요하다.
- [확정] 실명은 고객 이름 확인용이며 **본인이 입력한 이름** 수준이다(이메일 인증은 이름을 검증하지 않는다). 실명은 **관리자와 해당 학습자의 담당 강사**만 열람한다.
- [확정] 닉네임은 선택; 입력하면 중복 불가. 미입력은 **형용사 + 동물명사 + 1~999** 형태로 임의 고유 닉네임 생성하고 중복 시 재생성. 실명·아이디를 공개 표시명으로 사용하지 않는다.
- [확정] 회원가입 후 자동 로그인 없음. **첫 로그인** 취미 탐색, **이후 로그인** 메인 홈.
- [확정] 이메일 소유 확인을 통한 아이디 찾기/비밀번호 재설정 기능을 MVP에 포함.
- [확정] 동일 계정의 동시 다중 기기 로그인 불가; 새 로그인은 기존 기기의 세션 종료.
- [확정] 세션은 **마지막 요청 후 1시간 유휴** 기준으로 만료한다. 영상 학습 화면의 **재생 중·일시정지 중에는** 정해진 범위에서 로그인 상태가 유지된다(일시정지는 유휴 시간으로 계산하지 않음). 만료로 로그아웃되면 홈 이동.
- [확정] 브라우저를 종료한 뒤 재접속하면 다시 로그인해야 한다. 내부 로그인 정보의 즉시 파기 여부 및 유지 방식은 개발 설계에서 확인한다.
- [확정] 일시정지 중 로그인 유지의 추가 허용 시간은 **일시정지 시작 후 최대 2시간**이다. 이후에는 일반 1시간 유휴 규칙을 적용한다(최대 3시간 뒤 로그아웃). 다시 재생하면 상한 계산을 새로 시작한다. 실습형 서비스라 영상을 멈추고 오래 실습하는 것이 정상 사용이기 때문이다.
- [추천 기본값] 로그인 식별자 영문 대소문자 처리와 앞뒤 공백, 비밀번호 길이 정책은 검증된 보안/사용성 기준으로 구현(실제 상세 설정은 개발 회의).
- [필수 보안] 비밀번호를 평문으로 보관하거나 인증 비밀정보를 노출하지 않으며, 로그인과 권한을 안전하게 보호한다. 구체적인 보관·검증 방식은 `DEV_REVIEW.md`에서 검토한다.

- [확정] 신규 세부 취미가 ‘운영 중’이 되려면 입문·중급·고급에 각 공개 가능한 강의 **1개 이상**이 있어야 함. 운영 중 대분류에는 운영 가능한 세부 취미 **1개 이상** 필요. [확정 D-31] 하위 취미의 준비 중 전환 등으로 이 조건이 깨지면 시스템이 자동 변경하지 않고 관리자 화면에 **대분류 상태 재설정 필요**를 표시하며 관리자가 변경한다.
- [확정] 상위 대분류 비공개 시 하위도 USER에게 숨김. 상위 재공개 후 하위 상태는 관리자 재설정.
- [확정] 이름 변경 시 내부 식별자·URL·연결 학습 기록 유지. 카테고리 삭제/복구해도 기존 수료 데이터 보존; 복구만으로 강의 자동 재공개하지 않음.
- [확정] 데이터로 카테고리를 추가하면 **같은 공통 화면**을 사용하고 새 취미마다 별도 페이지 개발을 요구하지 않음.

## 4. 강의·차시·분반·정원·대기·수강기간

### 4-1. 콘텐츠/담당 구조

- **[확정]** 운영 중 세부 취미 3개×수준 3개 = **초기 공통 강의 9개**. **강의마다 3개 필수 차시**(총 27차시)와 최종 과제 1개다. 3차시 이수는 서로 다른 3강의 수강이 아니다. 실제 영상 파일 구성/총수는 본 PDF에서 확정하지 않았다.
- **[확정] 공통 강의:** 관리자가 제공하는 **동일 영상·차시·최종 과제**를 여러 전문 강사가 **분반별** 담당한다. 학습자가 강사를 고르지 않고 이용 가능한 분반에 **자동 배정**된다. 대기 중에는 분반 미확정, **자동 확정되는 순간 분반 지정**. 배정 규칙은 §4-3(D-52).
- **[확장 D-45] 개인 제작 강의:** 제작·등록한 강사가 원칙상 담당하고 강의별 정원을 자율 설정하며 통일 상한·합산 상한을 두지 않는다는 PDF 방향은 **확장 도입 시 정책으로 보존**한다. MVP 강의는 관리자 공통 강의만 운영하며 강사의 강의 생성·정원 설정 기능은 없다.
- **[기존 유지]** 입문/중급/고급은 선행 수료 조건 없이 선택한다. 차시 목표·성취 기준과 준비물 텍스트를 제공한다. 현재는 자체 업로드 영상·각 차시 실제 재생 시간 60% 기준을 유지하고, 완료 뒤 다음 화면으로 자동 이동하지 않는다.

### 4-2. 공통 분반 정원·자리 점유

- **[확정 D-52]** 분반별 정원은 **1~30 활성 수강 확정 건**이다. **강사 1명의 공통 강의 합산 30건 검사는 하지 않는다**(구 합산 상한 삭제). 동일 학습자가 서로 다른 강의를 수강한 경우 각 수강 건을 1건씩 계산한다. 분반 정원은 현재 활성 수강 수보다 작게 줄일 수 없다.
- **[확정 D-53]** 초대 예약 좌석이 없으므로 정원은 **활성 수강 확정 건만** 센다. 자리가 반환되면 같은 처리 안에서 대기 1순위를 확정해 정원 초과·중복 확정을 막는다.
- **계속 점유:** 수강 확정 학습 중, 최초 제출 후 평가 대기/평가 진행, **30일 이내 반려·재제출 가능**, 반려 후 정식 재제출 평가 대기, **30일 경과했어도 기간 내 제출한 과제가 평가 미완료**인 경우(평가 완료까지).
- **즉시 반환:** 필수 피드백+수료 승인 완료, 30일 만료했지만 평가할 과제가 없음, 만료 후 최종 평가 반려, **평가 대기·진행이 아닌 상태에서 자발적 수강 취소**. **반환되는 즉시 대기 1순위를 자동 확정**한다(D-54·E6).
- **반환 아님:** 평가 시작 취소. 분반 담당 변경(D-59)은 정원 반환이 아니다. 수료자는 정원 반환 후에도 영상 무제한 재시청. (오반려 정정 시 반환 정원 재점유 없음 원칙은 [확장 D-37] 도입 시 적용.)

### 4-3. 공통 강의별 단일 대기열(FIFO)·자동 확정

- **[확정 D-53 · FR-053 P0]** 대기 순번은 **강의별 하나(FIFO)**이며 분반별 개별 대기열을 두지 않는다. 자리가 나면(수료 승인·수강 취소·만료 반환·정원 증가) **대기 1순위를 즉시 수강 확정**하고 남은 자리만큼 다음 순번을 이어서 확정한다. **초대·수락·48시간 유효 기간·관리자 수동 발급은 없다**(구 D-39 대체).
- **[확정 D-53·D-57]** 자동 확정되면 그 분반의 수강 건으로 확정되고 **30일 수강기간이 그 시각부터 시작**한다. 학습자에게는 **사이트 알림**만 보낸다(이메일 없음). 자동 확정을 원하지 않으면 학습자는 대기 중에 스스로 대기를 취소해야 한다.
- **[확정]** 대기 신청 취소 시 순번 소멸, 다시 대기하면 마지막 순번. 학습 중/대기 중 동일 강의 중복 신청 불가, **수료·취소·만료한 강의는 신청·대기 불가(D-35·D-55)**. 관리자는 대기열을 **조회만** 한다(D-59).
- **[확정 D-52 · FR-052 P0 · 구 D-38 대체] 분반 자동 배정 규칙 (한 줄):** **담당 강사가 있는 분반 중 남은 자리(정원 − 활성 수강)가 가장 큰 분반에 배정한다.** 같으면 분반 번호가 빠른 분반. 대기자가 있으면 신규 신청은 빈자리로 직행하지 않고 대기열 끝에 선다. 담당 강사가 있는 분반이 없으면 신규 신청·대기를 받지 않는다. 대기 1순위 자동 확정 때도 같은 규칙을 쓴다.

### 4-4. 30일 수강기간·취소·재신청 불가

- **[확정]** 수강기간은 **수강 확정 시점부터 30×24시간**. 3차시 학습·최종 과제 최초 제출·반려 후 정식 재제출은 이 기간 내에서만 허용. **만료 후 신규 제출/재제출 불가**. 만료 전 정상 제출된 과제는 이후에도 강사가 평가하며 해당 정원을 결과 확정까지 점유한다.
- **[확정 D-55 · FR-055 P1]** **같은 강의는 한 번만 수강한다.** 수료한 강의(D-35)뿐 아니라 **취소·만료(미수료)한 강의도 이번 MVP에서는 재신청·대기할 수 없다.** 반려는 수강기간 안의 정식 재제출로만 이어진다. (구 '수강 확정 시각+30일 후 재신청' 규칙은 보류.)
- **[확정 D-54 · E6]** 평가 대기·진행 중에는 수강 취소 불가. 그 밖의 수강 중 상태에서는 자발 취소 가능하며, 취소 화면에 **'취소한 강의는 다시 신청할 수 없습니다'**를 안내한다. 취소 즉시 **자리 반환 → 대기 1순위 자동 확정 → 그 학습자에게 사이트 알림**. 다른 강의의 수강/대기는 독립 허용.
- **[보류 D-55]** 재신청 불가로 새 수강 회차가 생기지 않으므로 이전 기록 삭제(D-36)·이전 시도 보관(D-44·FR-056)은 이번 범위에서 적용 대상이 없다. 재신청을 다시 허용할 때 함께 재검토한다. **[확정 D-35] 수료한 강의는 재수강 불가**(재시청으로 대체).
- **[확정 D-42] 영상 접근 = 수강 30일 이내 또는 수료자.** 미수료로 만료된 회차는 영상 시청·신규 제출이 불가하며 기간 내 제출 과제의 평가·결과 조회만 유지한다. 영상 제공 종료는 수강기간 만료와 다른 사건이며 종료 공지 후 신규 신청만 차단한다. 구 D-05·R-05의 '60% 완료자 예외'는 폐기·대체되었다.
- **[확정 D-41]** 남은 수강기간이 7일 미만(수강 확정 후 23일 경과)이면 최종 과제 제출 화면과 학습 현황에 **‘반려 시 재제출 기회가 없을 수 있음’**을 안내한다.

## 5. 최종 과제·정식 재제출·일반 작품·성장 기록

### 5-0. 평가 시작과 제출물 상태

- **[확정]** 최종 과제는 **세 차시 모두 완료**한 뒤 원본 JPG/PNG/WebP 이미지 1~5장(장당 최대 50MB)·설명으로 제출한다. 파일이 1장이라도 실패하면 미제출이다. **제출만으로 수료하지 않고 `평가 대기`에 진입**한다. 제목은 강의명 기반 기본값(수정 선택), 공개는 기본 비공개다.
- **[확정]** 수강기간 안에서 **평가 시작 전**에는 학습자가 제출물 내용을 수정하거나 임시저장할 수 있으며, **수정만으로 새 평가 요청·7일 재기산이 발생하지 않는다**. 반려 후 정식으로 **`재제출`을 클릭**해야 새로운 제출/새 7일 기한이 성립한다. 재제출 횟수 제한 없음.
- **[확정]** 담당 강사가 과제를 **열람하는 것만으로** 수정이 잠기지 않는다. **`평가 시작` 클릭 순간**부터 `평가 진행 중`·수정 잠금. **평가 내용을 쓰기 전 본인만** 시작 취소 가능, 취소 시 평가 대기 복귀·기한 유지·30일 이내인 경우에 한해 수정 재개.
- **[확정]** 수강 회차별 **동시 평가 대기 최종 과제는 1개만**. 과제 수정·임시저장은 복수 병렬 평가 대기를 생성하지 않는다. 강사 재배정은 수정 잠금·초안·마감일을 그대로 승계한다.
- **[확정]** **모든 필수 차시+담당 전문강사의 최종 수료 승인(공식 피드백 최소 50자)**을 충족할 때에만 수료 확정. **반려 사유 필수**이며 반려는 미수료, 잔여 30일 안에 재제출 가능. 30일 지난 뒤 최종 반려면 같은 회차 재제출 불가.
- **[확장 D-37]** 승인·반려 결과를 강사가 사후에 바꾸는 **오반려 정정은 MVP에서 제공하지 않는다**(U05 포함 확장 이관). 확장 도입 시 반환된 정원 재점유 없음 원칙을 적용한다.
- **[기존 유지]** 일반 작품은 최종 과제와 구별하여 여러 개 등록할 수 있고, 운영 중 취미·배지에 따른 수준 태그·기본 비공개·원본 이미지 규칙과 별도로 관리한다. **일반 작품 등록 자체는 수료에 영향 없음**.
- **[기존 유지]** 개인 성장 타임라인에 최종 과제/일반 작품을 날짜순 표시하고 선택적 한 줄 회고, 취미별 최초/최근 작품 썸네일, 참고 공식 피드백의 선택 연결을 제공한다(기존 FR-027/028의 P1 유지). 공식 피드백은 승인 완료한 기록만 참고할 수 있다.
- **[변경]** 기존의 **`최종 과제 제출=수료일`**은 폐기: 제출일·수정일·평가 시작일·반려일·**수료 승인일**을 구분한다. 제출 후 피드백 이전 수정에 따른 기한 7일 재시작도 폐기한다. 수료 승인 후 자료 수정 허용 범위는 PDF에 미확정.
- **[변경]** **수료 철회·배지 유예·무효 후 30일 보완기간 기능 자체 폐기**. 일반 작품 직접 삭제(P2)는 유지. 구 D-32의 **완료된 최종 과제 삭제→즉시 수료 철회**는 폐기된 철회 기능에 종속되어 그대로 수행할 수 없으므로, 완료 과제 직접 삭제 시 후속 데이터·수료 상태 정책을 **별도 미정**으로 둔다. 이를 빌미로 승인을 자동 철회하지 않는다.
- **[기존 유지]** 관리자 공개 작품 숨김·복구(P1)는 일반 이용자의 노출만 바꾸며 작성자·현재 담당 강사의 최종 제출물 접근, 평가 의무/기한, 수료 확정은 유지한다. 신고 기능은 여전히 [확장].

### 5-1. 작품 수준 태그 검증 시점 [확정 보완]

- **강의 신청 수준 선택**은 선행 수료 여부와 무관하게 입문·중급·고급 자유 선택한다. **일반 작품 태그**만 아래 배지 범위에 제한된다.
- 일반 작품 **신규 등록 또는 수준 태그 변경** 시 해당 취미의 **현재 유효한 최고 배지**(폐기된 유예 기능은 적용하지 않음)가 선택 가능 범위를 정한다. 배지가 없으면 `입문`만, 입문 보유 시 입문만, 중급 보유 시 입문/중급, 고급 보유 시 세 수준 중 선택할 수 있다.
- 기존 작품의 태그는 배지 판단 조건이 달라져도 임의 소급 변경하지 않는다. 배지 유예·수료 철회 제도는 폐기됐다. 댓글을 작성하는 사람의 배지 자격은 **댓글 작성 시점**에 재판정한다. 입문 작품이라고 배지 없는 이용자의 댓글까지 허용하지는 않는다.

## 6. 강사 승인 수료·수준 배지·마스터 배지

- **[확정 2026-10-30]** `3차시 학습 완료 → 최종 과제 제출 → 현재 담당 전문강사 평가 → (공식 피드백 최소 50자 + 수료 승인) → 수료 확정·수준 배지`. **제출 시 자동 수료 정책은 폐기**. 반려 시 미수료이며 강사는 반려 사유를 작성한다.
- **[확정]** 하나의 취미·수준에서 **승인 완료된 인정 강의가 최소 1개**이면 그 수준 배지 인정. 동일 취미의 입문·중급·고급 모두 이 조건을 만족하면 마스터 배지. 다른 동일 수준 강의의 미수료나 신규 등록·수강으로 이미 유효한 배지를 소급 박탈하지 않는다.
- **[확정]** 배지·댓글 권한은 기존 취미/수준별 자격을 적용하며, 작성자의 자기 작품 답글 예외는 유지한다. 수료 승인 이후 강의 영상은 기간 제한 없이 재시청 가능하다.
- **[폐기]** 수료 완료 후 과제 무효에 따른 수료 철회, 14일/30일 배지 유예, 철회 뒤 별도 30일 재수료 보완기간, 과거 자동 재수료/오판 무효 정정 복구 시나리오는 **운영 정책에서 삭제**한다. PDF의 '만료 후 반려→수료 승인 오정정'은 **강사 최종 평가의 오반려 정정**으로 이 폐기 목록과 다르며, 2026-10-31 **[확장](D-37)**으로 이관했다.
- **[미정]** 승인 완료된 최종 과제의 작성자 직접 삭제 후처리는 추가 정책 결정을 따른다. 별도 합의 전 수료를 자동 철회하지 않는다. (재수강 시 배지 처리 U03은 수료 강의 재수강 불가(D-35)로 대상이 없어 종결.)

## 7. 강사 LMS·과제 평가·피드백·통계

### 7-0. 현재 강사의 학습자 관리 권한

- **[확정]** 강사는 로그인 직후 **본인 담당 강의·분반 목록**을 보고 본인 분반의 학습자 이름, 수강 강의, 차시별 완료/진도율, 남은 수강기간, 과제 상태·제출 이력·공식 피드백 이력을 조회한다. 타 강사 분반의 학습자 개인 기록 조회는 허용하지 않는다.
- **[확정]** 평가 목록에 **대기 / 진행 중 / 완료** 탭과 **마감 임박(48시간 이하) / 기한 초과** 상태를 둔다. 실습 제출물 평가 및 공식 피드백/반려 처리는 현재 담당 전문강사의 권한이다.
- **[확정]** 강사는 수강생에게 서비스 내에서 임의의 **직접 메시지·일방 알림을 발송하지 못한다**. 학습자 질문에 응답하는 기존 1:1 문의/작품 댓글은 별도 기능·우선순위를 유지한다.
- **[확정]** 공통 강사 과부하 여부는 **평가 대기 건수 + 남은 평가 기한**을 함께 고려하되 수치/조합 방식은 **미정(U10)**. 자동 수료/자동 반려는 하지 않는다. (개인 제작 강사 지연 Q28·U12는 [확장 D-45].)

### 7-1. 공식 평가·고정 7일 기한

- **[확정]** 최초 제출일, 반려 후 **정식 재제출일**로부터 각각 7×24시간의 공식 최종 평가 기한을 적용한다. 학습자의 사전 수정/임시저장, 강사의 **평가 시작 취소**, 담당 강사 **재배정**으로 기존 기한은 재시작하지 않는다.
- **[확정]** 공식 승인 때 **50자 이상 피드백 필수**(잘한 점/개선할 점/다음 연습은 가이드); 반려 때 **반려 사유 필수**. 시작 취소는 담당 본인이 **평가 내용을 아직 입력하지 않은 상태**에서만 가능. 평가 시작 즉시 수정 잠금, 단순 열람은 수정 잠금 아님.
- **[확정]** 48시간 이하 남은 미완료 평가 건은 마감 임박, 기한 초과 건은 별도 표시. 기한이 지나거나 **30일 수강기간이 만료되어도 기간 내 제출된 과제의 평가 의무는 끝나지 않는다**. 만료 뒤 반려 시 기존 수강 회차 재제출 불가.
- **[확정 D-59 · 구 D-40 대체]** 공통 강사의 활동 중단·지연·정지 시 관리자는 분반 관리에서 **분반 담당 강사를 다른 적격 강사로 변경**한다(수강생 분반 이동 없음). 분반의 수강 회차·진도·30일 기간·과제 상태·**진행 중 피드백 초안·수정 잠금·7일 마감**을 새 담당자가 그대로 승계하고 이전 강사의 수정권은 즉시 종료한다. 이미 완료된 과거 피드백은 새 담당자의 읽기 전용(Q-04).
- **[기존 FR-044(P2) 유지]** 경고·담당 자격 정지의 부여/분기 누적 등 세부 운영은 기존 P2로 유지하되, **구 규칙 중 '수정/인계/공백으로 새 기한 168시간 부여'는 마감 고정 규칙으로 대체**한다. **[확정 D-43]** 기한은 고정, 담당 변경으로 새로 담당한 강사에게는 **인계 후 유예 시간 동안 경고 판정 제외**, 인계 전 발생 지연은 이전 담당자 귀속(소급 삭제 없음). 유예 시간 수치는 P2 구현 시 결정.
- **[확정]** 관리자가 숨긴 공개 작품에 대해서도 작성자·현재 담당자는 계속 접근하고 기한/평가 의무를 이행한다. 관리자는 일반 공식 최종 평가(수료 승인/반려)를 수행하지 않는다.

### 7-2. 강사 통계·가시성 [MVP P0 · D-58 현재 숫자만]

- **[P0 승격 확정]** 기존 강사 통계 P1을 **P0**로 승격한다. **이외의 FR 우선순위를 바꾸지 않는다.**
- **조회자:** 강사 **본인**과 관리자. 학습자와 다른 강사는 볼 수 없다.
- **항목 [D-58]:** **현재 숫자만** — 담당 분반별 **수강 중·수료·반려·평가 대기 수**. 월별 수강·수료 추이, 강의별 수료율·평균 진도율, 과거 운영 실적은 이번 범위에서 제외(후속).
- **집계 방식:** 현재 수강·평가 상태에서 바로 센다. 재신청 불가(D-55)로 개인 기록 삭제가 없으므로 별도 스냅샷·소급 보존 설계가 필요 없다.

### 7-3. 개인 제작 강사 활동 중단 [확장 Q21~Q25]

- **[확장]** 활동 중단 즉시 개인 제작 강의의 신규 수강 신청·신규 대기 초대 중단. 기존 유효 초대 처리·대기열 보존은 미정(U06).
- **[확장]** 강사 부재로 정상 피드백 불가 시 피해 학습자별로 관리자가 **수강기간 연장 기간을 재량 결정**하여 학습 기회 회복을 우선한다. 기본 30일의 예외이며 상한·종료 후 재개/재제출 가능 범위는 미정(U08).
- **[확장]** 복귀 불가 시 관리자가 다른 적격 **전문강사**를 임시 평가 담당자로 지정한다. 미완료 평가·초안을 인계하고 강의 신규 신청 중지·기간 조정·운영 종료까지 개입할 수 있다. **관리자 본인이 일반 최종 과제 평가자가 되는 것은 아님**. 종료 시 기존 수강자/대기자 처리 미정(U09).
- **[확장]** 강사별 개인 제작 정원·합산 정원에 새 상한을 임의 추가하지 않는다. 기한 초과 시 자동 승인/반려 대신 관리자에게 지연을 알리고 개입 여부를 판단한다.

### 7-4. 준강사 [확장 Q30]

- 준강사 도입 시 역할은 **학습 질문 응답·실습 보조만**. 전문강사만 공식 평가·수료 승인·반려 가능. 준강사 신청/승인/실제 보조 기능은 여전히 **MVP 제외**.

## 8. 게시판·관리자 조치·공개 권한 (신고는 확장 D-33)

- **[현행 MVP 범위]** 신고 접수·처리는 이번 MVP 밖의 [확장]이다. **관리자 과제 무효로 인한 수료 철회·배지 14일 유예·무효 후 재수료·무효 원본 30일 보관·무효 오판 복구는 이번 PDF에서 폐기**한다. 관리자는 **공개 작품만 숨김·복구**한다(Q-01). 숨김 과제는 작성자·현재 담당 강사가 열람 가능하고 수료·배지·피드백 책임/기한은 유지한다(Q-02). **일반 작품 직접 삭제 D-32는 별개 P2 기능**이며, 수료 완료 과제 직접 삭제의 수료 처리 결과는 재결정 전 보류다.
- [확정] 취미별 작품 게시판, 검색·필터·정렬. [확정 D-09] 기본 정렬 **최신 공개순**, 정렬 선택 최신순/좋아요순, 필터 **세부 취미·수준 태그·작품 유형(최종 과제/일반 작품)**, 검색 대상 **작품 제목·작가 닉네임**(P2). 작품은 기본 비공개이며 공개 작품만 일반 학습자/취미 권한 강사가 확인.
- [확정] **본인 작품 좋아요 가능**, 사용자별 중복 좋아요 방지 및 취소. **자기 댓글 수정·삭제 가능**, 답글 **1단계**. 작성자 **자발 삭제 댓글**은 본문을 ‘삭제된 댓글입니다’로 치환하고 타인 답글 유지. 작성자 **탈퇴만 한 정상 댓글**은 본문 내 식별정보를 비식별 처리한 뒤 원칙적으로 내용을 보존하고 탈퇴 표시명으로 익명화한다(D-25). 자발 삭제가 우선한 본문은 탈퇴 후에도 복원하지 않는다. 신고 숨김 여부는 별도 운영 상태다(확장 D-33).
- [확장 D-33] 작품·댓글·공식 피드백 **신고**. 담당 강사는 담당 강의의 작성자 비공개 최종 과제도 신고할 수 있다. 신고 접수만으로 과제 자동 무효 처리하지 않는다.
- [확정 Q-01/Q-02] 관리자는 **공개 최종 과제·일반 작품 숨김·복구만** 한다(댓글 개별 조치·작품 직접 삭제 없음). 일반 이용자는 숨긴 작품 원본 URL까지 차단되지만 작성자·담당 강사는 계속 열람한다. 숨김은 수료·배지·피드백 책임에 영향 없음.
- **[폐기 D-15 관련 구 기준]** 제출물의 파일 요건 충족은 수료가 아닌 **평가 대기**를 뜻한다. 무효에 따른 수료 철회 정책은 폐기했다.
- [확장 D-33 · 기존 확정 D-02] 관리자는 신고를 **접수 후 7×24시간 안에 처리하도록 권장**한다(경고·제재 없음). 이를 넘긴 미처리 신고는 관리자 신고 목록 **최상단에 표시**한다(P2). 신고 처리 중 수정 잠금은 그대로 유지한다.
- [확장 D-33 · 기존 확정 D-24] **동일 신고 대상(작품·댓글·공식 피드백·1:1 문의 등)과 동일 사유에 대한 진행 중 신고**는 신고자가 달라도 하나의 사건으로 병합한다. 개별 신고 접수 내역은 남기되 검토 사건의 접수 시각·처리 권장 기한(최초 접수+7×24시간)·수정 잠금을 새로 시작하지 않는다. 대상이 작품인 경우 **수정 잠금은 진행 중인 사건 기준으로 한 번만 적용**한다. 이미 종결된 사건과 동일한 내용이 새 증거·대상 변경 없이 반복 신고되면 **중복 접수 안내만 하고 자동 재잠금·재심사를 시작하지 않는다**. **진행 중인 동일 대상·사유 사건에 추가된 증거는 해당 사건에 첨부**한다. 사건 종결 **이후** 새로운 증거가 제출되거나 대상 콘텐츠가 변경됐거나 다른 사유의 신고가 들어오면 관리자가 새 검토 사건의 필요성을 판단한다. 진행 중인 사건의 종료·잠금 해제는 사건 처리 결과에 따른 기존 원칙을 유지한다.
- [확정 Q-01/Q-02] 관리자 공개 작품 **숨김·복구 사유는 작성자 전용 서비스 내 화면(U-S16)에서 확인**할 수 있다. **[D-57] 관리자 조치 이메일 통지는 사이트 알림으로 대체**한다(이메일 알림 없음). 숨김·복구 사실은 사이트 알림과 서비스 내 사유 화면으로만 전달한다. **신고 결과·관리자 과제 무효·오판 정정 이메일 통지는 확장**이다. 정식 이의제기도 확장이다. (2026-11-05 D-57로 이메일 알림 제외를 팀 결정.)
- [확장 D-33 · 기존 확정 D-21] 공식 피드백 신고 시 문제없음·숨김·강사 수정 요청 중 조치한다. **수정 요청한 피드백은 확인이 끝날 때까지 숨김**, 강사가 수정해도 자동 재공개하지 않는다. **관리자가 수정 결과를 최종 확인·승인한 후에만 재공개**한다. 숨김 중에는 학습자 목록·성장 기록의 참고 피드백에도 원문을 노출하지 않는다. 관리자는 강사 원문을 직접 수정하지 않는다.

## 9. 탈퇴·익명 보존·무효 자료 삭제

- [확정] USER 탈퇴는 **계정 즉시 이용 차단 및 직접 식별·인증정보 제거**, 수강/진도·수료/배지·복습/강사 피드백·본인 최종 과제/일반 작품·이미지/공개 게시물 **삭제**를 원칙으로 한다. 데이터 관계 유지를 위한 **비식별 계정 껍데기(탈퇴 상태)**는 남길 수 있으나 개인정보·학습 데이터의 삭제를 대신할 수 없다.
- [확정] 탈퇴 시 이메일 원문은 삭제한다. 30일 재가입 제한 확인에 필요한 **이메일 원문이 아닌 확인값**만 30일 보관 후 삭제한다. 확인값의 안전한 생성·보관 방식은 `DEV_REVIEW.md`에서 관리한다.
- [확정] MVP에서는 탈퇴 시 1:1 문의 스레드를 전체 삭제한다. [확장 D-33] 신고 기능 도입 시: **진행 중 신고가 없는 1:1 문의 스레드는 전체 삭제**한다. 신고가 진행 중인 스레드는 비공개·최소 접근 상태로 예외 보존 후 신고 종료와 보존 의무 확인에 따라 삭제한다. `신고 진행 여부`는 삭제 시점의 최신 사건 상태를 기준으로 판정한다.
- [확정] 타인 작품의 **정상 상태 댓글**은 탈퇴 처리 시 본문 식별정보를 확인·비식별 처리한 뒤 계정 연결을 해제하여 **안전한 범위에서 본문을 익명 보존**하고 작성자는 `--탈퇴한 사용자 입니다--`로 표시한다(D-25). **자발 삭제한 댓글**은 `삭제된 댓글입니다` 본문 상태를 그대로 유지한다. 타인의 답글과 작성자 정보는 그대로 보존하며, 탈퇴 전 원 계정으로 역추적 가능한 작성자 연결은 남기지 않는다.
- [확정 D-25] **댓글의 작성자 익명화와 본문 개인정보 처리는 별개**다. 회원 탈퇴 과정에서 원 계정 연결을 해제하기 **전에** 해당 이용자가 타인 작품에 남긴 댓글에 이메일·전화번호·실명·외부 계정 등 식별 가능한 정보가 포함됐는지 확인한다. 발견 시 **식별 부분을 마스킹하거나 안전한 문구로 치환**하고 나머지 내용을 보존한다. 일부만 가려도 재식별 가능하면 **본문 전체를 비공개/삭제·대체 처리**하되 부모 댓글 자리와 다른 이용자의 답글은 유지한다. 이미 자발 삭제된 댓글의 본문은 복원하지 않는다. 자동 탐지만으로 완전한 비식별을 보장하지 않으며 필요 시 관리자 점검(이용자 신고는 확장 D-33)으로 보완한다. [확장 D-33] **진행 중 신고의 필요한 증거만 접근 제한된 비공개 상태로 예외 보존**하고 사건 종료·보존 의무 확인 후 정리하며 공개 원문은 되살리지 않는다.
- [확정] 탈퇴자 좋아요 반응/집계는 익명으로 남기고 계정별 중복 검사·취소 식별 정보는 탈퇴와 함께 정리한다.
- [확장 D-33] 완료된 일반 신고는 탈퇴 시 삭제. **진행 중 신고 및 관련 필요 증거**와 필요한 최소 신고자 신원은 사건 처리 완료까지 예외 보존하고 이후 보존 의무 확인 후 정리.
- [확장 D-33] 탈퇴자가 **신고당한 쪽**인 경우에도, 진행 중 신고의 대상 작품·댓글은 처리 완료까지 비공개로 보존한 뒤 삭제한다.
- **[폐기]** 관리자 무효→수료 철회 및 30일 보완/14일 유예·오판 무효 복구 제도는 사용하지 않는다. **탈퇴 이메일 재가입 제한 확인값의 30일 보관은 별개로 유지**한다.
- [기술/운영 검증] 예외 보존 근거는 운영에서 확인하고, 실제 파일·기록 파기 방법과 실패 재처리는 `DEV_REVIEW.md`에서 검토한다. 본 기획만으로 법정 보존·파기 의무 충족을 보장하지 않는다.
