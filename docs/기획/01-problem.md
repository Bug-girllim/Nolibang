## 1. 해결하려는 문제

많은 취미 학습에서는 **강의 시청과 최종 작품 완성**은 기록되지만, 학습자가 이전에 무엇을 어려워했고 어떤 피드백을 받았으며 다음 실습에서 무엇이 달라졌는지를 하나의 학습 맥락으로 계속 따라가기가 번거롭다. 이는 모든 기존 제품에 그런 기능이 없다는 주장이 아니라 **본 프로젝트가 개선하려는 사용자 경험 가설**이다.

### 주 사용자

- **학습자(USER):** 그림이나 베이킹 등을 처음 시작하거나 실력을 개선하고 싶으며, 경쟁/점수보다 개인적인 성장과 격려를 선호하는 사람.
- **강사(INSTRUCTOR):** 배정된 공통 강의 분반의 3차시 학습·수강기간·제출 이력과 평가 현황을 관리하고, **수료 승인/반려 및 필수 피드백**을 제공하는 전문 강사.
- **관리자(ADMIN):** 강사 계정(임시 비밀번호)·공통 강의 분반(생성·담당·정원)·대기열 조회·강사 통계와 교육 제공 상태를(카테고리·강의는 시드 데이터, D-59) 일관되게 관리해야 하는 운영자.

### 비교 해석

**이미 시장에 존재:** 영상 강의, 최종 프로젝트, 갤러리, 배지, 강사 피드백, 학습 경로, 포트폴리오, 챌린지, 강의 판매.  
**이번 프로젝트가 강조할 연결:** **작은 실습의 실패·변화 기록 → 구체적인 개선 피드백 → 다음 시도**를 취미·수준별로 한 곳에 누적한다. 이는 기능의 최초 발명이 아니라 **설계 조합과 이용 경험의 차별화 가설**이다.

### 3-1. 최종 LMS 동작 기준 (2026-10-30)

프로젝트의 차별화는 제출 즉시 발급되는 자동 수료가 아니라, **취미별 3차시 학습 → 최종 작품 → 실제 담당 강사의 평가·50자 이상 피드백·수료 승인 → 성장 기록**으로 실습 경험을 체계적으로 남기는 데 있다. 공통 강의를 여러 전문강사 분반으로 운영하며, **강의별 단일 대기열(FIFO)·자리가 나면 1순위 자동 확정·30일 수강기간**과 **강사의 수강생·평가·정원·통계 관리(P0)**가 실제 LMS 운영의 핵심이다. 수료자 영상 무제한 다시 보기를 지키고, 강사 통계는 분반별 현재 숫자(수강 중·수료·반려·평가 대기)로 단순화했다(D-58). 준강사·개인 제작 강의 전체·강사 오반려 정정은 후속 확장이다. [2026-11-05 D-55: 이번 MVP는 수료·취소·만료한 강의 재신청 불가 → 아래 재수강 보관 흐름은 보류] 재수강 시 실패한 시도는 학습자가 선택하면 일반 작품으로 보관해 **실패→피드백(반려 사유 포함)→다음 시도** 기록을 이어 갈 수 있다(D-44·D-47).

## 4. 서비스 가치 제안

> **[임시 확정 슬로건 2026-10-28] “강의를 보는 곳이 아니라, 취미 실력이 쌓이는 LMS.”**
>
> 임시 확정이며 추후 수정할 수 있다. 아래 MVP 핵심 기능은 별도로 확정되어 있다.

1. **성장 기록 중심:** 최종 과제와 일반 작품을 날짜순 표시, 작품별 선택적 한 줄 회고, 같은 취미의 첫 작품·최근 작품 요약, 일반 작품 등록 시 최근 공식 피드백을 **선택하여 작품에 연결 저장하고 성장 기록에서 확인** **[기획 확정 D-17]**. 새 대형 기능이 아니라 기존 작품·피드백 데이터를 다시 보여 주는 방식으로 ‘피드백→다음 시도’ 연결을 강화한다.
2. **실습 개선형 피드백:** 잘한 점/개선할 점/다음 연습이라는 작성 가이드를 활용하고 기존 공식 피드백 규칙 유지 **[MVP 확정]**.
3. **강제하지 않는 연속 학습:** 입문·중급·고급을 자유롭게 선택하고 진도·수료·배지 상태를 확인. 세부 취미 상세에 세 수준 상태를 3칸으로 표시 **[MVP P2 확정]**, 별도 로드맵 화면은 확장.
4. **반복 실습 동기:** 7일·30일 챌린지와 별도 완주 배지 **[MVP 뒤 최우선 확장 확정]**.

### LMS로서 남겨야 할 본질

**역할/권한 → 공통 강의·분반 개설 및 담당 → 수강/대기 신청·자리가 나면 자동 확정 → 30일 안에 필수 3차시 학습(각 영상 60%) → 최종 실습 제출 → 담당 강사 평가·50자 이상 공식 피드백 및 수료 승인 → 수료·배지 → 학습 이력 관리.** 별도의 점수 시험이 필수는 아니지만, **최종 과제의 형식상 유효 제출만으로 수료되지는 않는다.**

## 5. 대표 사용자 상황(가설)

- **드로잉:** 첫 그림을 제출하면서 “그림자가 진했다”는 메모 → 강사의 광원 연습 추천 → 다음 그림을 일반 작품으로 저장해 변화 확인.
- **디저트 만들기:** 반죽과 결과물 사진·선택 회고 → 강사의 굽기/배합 개선 제안 → 다음 실습 사진 누적.
- **초보 학습자:** 입문을 선택해도, 경험자는 중급을 바로 선택해도 된다. 각 취미의 수료 기록은 독립적이다.

### 이번 개정과 시장조사의 관계

2026-10-28의 댓글/탈퇴 익명화, 일반 작품 수준 태그, 피드백 인계, 진도·삭제 검증 보완은 **서비스 내부 정책 및 개발 위험 검토**다. 외부 경쟁 서비스의 기능을 추가로 확인한 조사 결과가 아니며, 기존 시장조사 근거·차별화 가설을 소급 변경하지 않는다.
