# 03. 서비스 요구사항 · MVP 완료 기준

> **[2026-11-05 MVP 단순화 결정 D-51~D-59 · 이 문서의 모든 앞선 기준보다 우선]** ① 강사 계정은 관리자가 **임시 비밀번호로 즉시 생성**(메일 설정 링크 없음, 첫 로그인 시 비밀번호 변경, D-51·FR-012) ② 공통 강의 분반은 여러 개·정원 1~30 유지, 배정은 **남은 자리가 가장 큰 분반** 한 줄 규칙, **강사 합산 30건 검사 삭제**(D-52·FR-052) ③ **단일 대기열(FIFO)** 유지, 자리가 나면 **1순위를 즉시 수강 확정 + 사이트 알림**, 초대·수락·48시간 단계 없음(D-53·FR-053) ④ 수강 취소 → 자리 반환 → **대기 1순위 자동 확정**(D-54·E6) ⑤ 같은 강의는 **수료(D-35)뿐 아니라 취소·만료한 강의도 이번에는 재신청 불가**(D-55·FR-055 P1) — 재수강 기록 삭제(D-36)·이전 시도 보관(D-44·FR-056)은 대상이 없어 보류 ⑥ 평가는 **시작(잠금) → 초안 → 승인/반려**, 시작 취소, 마감 임박·기한 초과 경고 유지(D-56·FR-023·030·031) ⑦ 알림은 **사이트 알림만**: 평가 결과(승인/반려)·대기→자동 확정·수료, **이메일 알림 없음**(D-57·FR-035) ⑧ 강사 통계는 **현재 숫자만**: 분반별 수강 중·수료·반려·평가 대기 수(D-58·FR-051) ⑨ 관리자 MVP는 **강사 계정·분반(생성·담당·정원)·대기열 조회·관리자 홈**, 카테고리·강의는 **시드 데이터**(D-59). 결정 상세는 `05-policy.md` §14. 아래 본문에 남은 48시간 초대·합산 30건·재수강 회차·월별 통계 문구는 **결정 이력**으로만 본다.

> **[최종 통합 기준 · 2026-10-30 / 변경사항 PDF 우선]** 동일 주제에서 기존 문서와 충돌하는 내용은 `놀이방_LMS_채팅확정_변경사항_20261030_통합갱신본(2).pdf` 01~09장의 최종 결정으로 대체한다. **강의당 3차시, 담당 강사 평가·필수 피드백 후 수료, 수강 확정부터 30일, 강의별 단일 대기열·48시간 초대, 공통 분반/강사 정원, 강사 통계 P0**가 현행 기준이다. **과제 제출 즉시 자동 수료, 수료 철회·14일/30일 배지 유예, 무효 후 재수료 보완기간은 폐기**한다. 신고·준강사는 기존처럼 [확장]이며 **개인 제작 강의는 이탈 대응을 포함해 기능 전체가 [확장]**이다(10-31). 10-30 통합에서 변경된 P등급은 강사 통계 P1→P0였고, **10-31 팀 결정으로 분반 자동 배정·정원·단일 대기열·48시간 초대·30일 수강기간은 P0, 재신청 제한은 P1**로 지정했다. 그 밖에 기존 등급이 없는 항목은 임의로 P0로 지정하지 않는다. 구 D-xx·FR-xxx의 대체된 문구는 현행 정책이 아닌 결정 이력으로만 본다.

> **[2026-10-31 최종 확정 추가 결정 · 위 기준보다 우선]** ① **수료한 강의는 재수강 불가**(무제한 재시청으로 대체) ② 재수강 시 이전 개인 기록 삭제는 **새 수강 회차 확정 순간**(U04=B) ③ 분반 자동 배정은 **담당 강사 합산 여유가 큰 분반 우선**, 대기자가 있으면 빈자리 직행 금지, **담당 공백 분반은 신규 배정·초대 제외** ④ 48시간 초대는 **시스템 자동 발급**, 미수락 시 **대기열에서 제거** ⑤ 공통 강사 교체 시 **수강생을 다른 분반으로 이동** ⑥ 영상 접근은 **수강 30일 이내 또는 수료자** ⑦ 반려 사유는 최소 길이를 두고 **참고 피드백(D-17) 대상에 포함**, 재수강 전 **이전 시도를 일반 작품으로 보관**하는 선택지 제공 ⑧ **강사 오반려 정정·개인 제작 강의 전체는 [확장]**. 결정 ID D-34~D-50, 상세는 `05-policy.md` §13, 변경 기록은 `CHANGELOG_20261031.md`.

## 1. 범위·상태 표기

- **MVP 확정:** 팀이 현 시점에 포함하기로 결정한 기능. 구현 범위 내 구현 가능 여부는 개발 설계·검증 단계에서 별도로 확인한다.
- **문서 기준 [확정 D-11]:** 이 문서가 **구현 요구사항·우선순위·완료 조건의 정본**이다. 동작은 04/02/07, 정책은 05, 확장 로드맵은 00.
- **기획 우선순위 vs 실제 구현 범위:** 아래 P0/P1/P2는 기획상 우선순위다. 구현 범위 내 실제 구현 범위는 기획 완료 후 **MVP 재정의** 단계에서 확정한다.
- **MVP 내부 우선순위 [확정 2026-10-28]:**
  - **P0** 없으면 핵심 시연 불가(X-01 정상 경로 + 권한 차단). 카테고리·초기 9강의(**시드 데이터**, D-59)·3차시 학습, 강사 통계(FR-051, 현재 숫자만 D-58), **분반 자동 배정·정원(FR-052)·단일 대기열 자동 확정(FR-053)·30일 수강기간(FR-054)**, 관리자 홈·강사 계정·분반·대기열 조회의 제공은 P0에 포함한다(D-34·D-59, 시드 데이터 입력 방법은 `DEV_REVIEW.md`).
  - **P1** 차별성·핵심 정책 시연(게시판·배지 댓글·관리자 공개 작품 숨김·복구·성장 기록 등).
  - **P2** 시간이 남으면 구현(탈퇴 익명화·작성자 작품 삭제·영상 종료·경고 제도 등). 구현하지 못해도 정책은 유지한다.
- **조건/권한:** 오류·중복·공개/비공개·삭제·권한 등 MVP 상태를 구별한다. 관리자 과제 무효·신고·**강사 오반려 정정(D-37)·개인 제작 강의(D-45)**는 MVP 제외이며, 수료 철회·배지 유예·무효 후 재수료 기간은 폐기다.
- **미정:** 현재 정책에 없는 값을 임의 확정하지 않는다.
- **확장:** MVP에서 구현하지 않는다.
- **요구사항 집계 [2026-11-05 갱신]:** §2의 현행 정의 행은 **FR 42개(P0 19·P1 12·P2 8·확장 3)**이며 §3 **NFR 9개**를 합쳐 **현행 51개 정의 행**이다. FR-011·FR-014는 카테고리·강의를 **시드 데이터**로 대체하여 이번 MVP 범위에서 제외(D-59), FR-056은 재신청 불가(D-55)로 대상이 없어 **보류**했다. P등급이 바뀐 FR은 없다.
- **[이력] 요구사항 집계 [2026-10-31]:** §2의 정의 행은 **FR 45개(P0 19·P1 14·P2 8·확장 3·등급 미정 1)**이며, §3 **NFR 9개**를 합쳐 **현행 54개 정의 행**이다. 폐기 FR-037~039와 번호 결번은 집계하지 않는다. P0 중 FR-051은 10-30 PDF로 P1→P0 승격, FR-052~054는 10-31 신설 P0, FR-055는 신설 P1, FR-056은 신설·등급 미정이다.
- **FR-023 배지 판정 보충(기존 요구 유지):** 취미·수준당 유효 수료 강의가 **1개 이상**이면 배지가 유효하다. 다른 동일 수준 강의가 미수료·수강 중이어도 배지를 소급 철회하지 않는다. 초기 취미 3개×수준 3개 구조는 유지하되 공통 강의의 분반 및 후속 인정 강의 증설을 고려한다.

## 4. 종합 수용 시나리오(Acceptance Scenarios: P0/P1/P2 혼합)

1. **[P0 학습·평가]** 가입→강의/분반 신청(정원 시 확정, 만석 시 대기)→해당 강의 3차시 각각 60% 완료→최종 과제 유효 제출→**평가 대기(아직 미수료)**→담당 강사 평가 시작→50자 이상 피드백·수료 승인→수료일·배지·영상 재시청→학습자 알림함 조회.
2. **[P0 강사 통계]** 강사 홈에서 자기 담당 **분반별 수강 중·수료·반려·평가 대기 수**만 표시(D-58), 관리자만 다른 강사 통계 열람. 학습자 차단.
3. **[P0 정원·대기열 FR-052·053]** 남은 자리가 가장 큰 분반 배정, 만석이면 단일 대기열(FIFO) 진입, 수료·수강 취소로 자리가 나면 **대기 1순위 즉시 확정 + 사이트 알림**, 대기 취소·끝순번 재진입. 초대·수락·48시간·강사 합산 30건은 검증 대상이 아니다.
4. **[운영 정책 확인]** 재제출과 단순 수정 구별. 수강기간 내 반려→정식 재제출로만 7일 기한 새 시작, 수정/시작 취소/재배정에는 기한 고정, 평가 시작 즉시 수정 잠금 및 내용 작성 전 실수 취소 확인.
5. **[P0 30일 수강기간 FR-054]** 30일 지나도 기간 내 접수 과제는 평가하며 정원을 유지. 만료 후 반려 시 반환·같은 회차 재제출 금지. 미수료 만료자 영상 접근 차단·수료자 재시청. (오반려 정정은 확장 D-37로 시연하지 않음.)
6. **[P1 재신청 차단 FR-055]** 수료·취소·만료한 강의의 재신청·대기 차단과 안내 문구.
7. **[P1/P2 조건부]** 관리자 공개 작품 숨김·복구(수료·평가 의무 불변), 게시판·문의·일반 작품·탈퇴 등은 개별 FR의 기존 우선순위대로 검증. **폐기된 수료 철회/유예/무효 정정은 시연하지 않는다.**
