## 2. 기능별 상세 동작

### F-01. 계정 가입과 인증

- 가입 입력: 로그인 **아이디, 비밀번호, 실명, 이메일**은 필수. 닉네임은 선택이며 입력한 닉네임은 중복 불가.
- 이메일은 계정당 고유이며 탈퇴 후 30일이 지나야 재가입 가능. 실명은 **본인이 입력한 이름**이며 관리자·담당 강사만 열람.
- 닉네임 미입력 시 `형용사 + 동물명사 + 1~999`를 무작위 생성하고 중복이면 다시 생성. 실명과 아이디를 공개 프로필 이름으로 사용하지 않는다.
- 이메일 소유 확인을 완료해야 가입이 완료된다. 완료 후 **로그인 화면**으로 이동(자동 로그인 X).
- 아이디/비밀번호 로그인. 계정 찾기/비밀번호 재설정은 가입 이메일 인증을 사용.
- **첫 로그인:** 취미 탐색, **이후 로그인:** 메인 홈.
- 동시에 한 기기만 로그인 허용. 다른 기기 로그인 시 이전 세션 종료.
- 세션은 마지막 요청 후 **1시간 유휴** 만료. 영상 학습 화면은 재생·일시정지 중 로그인 상태를 유지한다(일시정지는 최대 2시간, 다시 재생하면 새로 계산). 브라우저 종료 뒤 재접속 시 재로그인하고, 로그인 만료 시 홈으로 이동한다. 내부 세션 관리 방식은 `DEV_REVIEW.md`에서 검토한다.
- 예외: 미인증, 중복 아이디/닉네임, 계정 없음, 인증 실패, 세션 만료, 다른 기기의 세션 갱신.

### F-02. 대분류/세부 취미 탐색·수준 설정

- 4개 대분류: **미술·드로잉**·**요리·베이킹**(운영), **공예**(준비 중), **사진·영상**(비공개).
- 운영 세부 취미: 색연필화, 디지털 드로잉, 디저트 만들기.
- 공예 하위: 목공·가죽공예·도자기·반지공예, 각 소개·썸네일 표시, **신청 불가**.
- 사진·영상 하위: 사진 촬영·영상 편집, MVP에서는 **관리자만** 목록·편집 접근. USER/강사 대상 비공개.
- 공개 취미의 입문/중급/고급은 선행 조건 없이 자유 선택. 세부 취미 상세에 세 수준의 내 상태(미수강/수강 중/수료·배지)를 3칸으로 표시(P2, 별도 로드맵 화면 없음). 취미별 수준 선택 상태와 수강 상태를 구분한다.
- 예외: 목록이 비었거나 하위 취미/강의가 비공개 또는 준비 중이면 맞는 안내만 제공하고 신청 차단.

### F-03. 강의 목록·상세·수강 신청·30일 기간

- 초기 운영 취미 3개×수준 3개 = 공통 강의 9개이며, **각 강의에는 필수 3차시와 최종 과제 1개**를 둔다. 공통 강의의 동일한 차시/영상/과제를 여러 전문 강사의 **분반**이 공유한다. **담당 강사는 학습자가 고르지 않고 시스템이 자동 지정**한다. **[D-52 배정 규칙 · FR-052 P0] 담당 강사가 있는 분반 중 남은 자리(정원 − 활성 수강)가 가장 큰 분반**(같으면 분반 번호순). 대기자가 있으면 신규 신청은 대기열 끝. **[이력: 구 D-38]** ① 그 강의 대기열이 비어 있고 예약되지 않은 빈자리가 있을 때만 즉시 확정(대기자가 있으면 빈자리 직행 금지) ② 담당 강사가 있고 분반·강사 합산 여유가 있는 분반 중 **담당 강사 합산 여유가 큰 분반 우선**(동률 처리는 개발 결정) ③ **담당 공백 분반은 신규 배정·초대 제외**, 모든 분반이 공백이면 신규 신청·대기 신청을 받지 않는다.
- **공통 분반별 정원 1~30 수강 건.** 학습자 고유 인원이 아니라 수강 확정 건수다. **강사 1명 합산 30건 검사는 하지 않는다**(D-52). 정원은 현재 활성 수강 수보다 작게 줄일 수 없다.
- **[FR-053 P0 · D-53] 공통 강의별 단일 대기열(FIFO)**을 운영하며 분반별 대기열을 별도로 만들지 않는다. 자리가 나면 **대기 1순위를 즉시 수강 확정**(분반은 위 배정 규칙)하고 **사이트 알림**을 보낸다. 초대·수락·48시간 유효 기간·관리자 수동 발급은 없다. 대기자는 확정 전 대기를 취소할 수 있고, 다시 대기하면 끝순번이다.
- **[FR-054 P0]** 실제 **수강 확정 시각부터 30일** 동안 3차시 학습 및 최종 과제 제출/정식 재제출을 허용한다. 대기 신청 시각은 기산점이 아니며, 자동 확정된 학습자는 **확정 시각**부터 30일이다. **영상 접근은 수강 30일 이내 또는 수료자**(D-42): 수료가 승인되면 원본 강의 영상은 기간 뒤에도 무제한 재시청, 미수료 만료자는 시청 불가(기간 내 제출 과제의 평가·결과 조회는 유지).
- **[FR-055 P1 · D-55]** 한 학습자의 **동일 강의 수강 중/대기 중 중복 신청 불가**. **같은 강의는 한 번만 수강**: 수료(D-35)·취소·만료한 강의는 이번 MVP에서 재신청·대기할 수 없다. 제한은 다른 강의로 전파하지 않는다.
- **개인 제작 강의 [확장 D-45]:** 강의 생성·정원 자율 설정·이탈 처리(Q21~25)를 포함해 기능 전체를 확장으로 둔다. PDF의 방향(제작 강사 책임, 강의별 자율 정원, 합산 상한 없음)은 확장 도입 시 정책으로 보존한다. MVP 강의는 관리자 공통 강의뿐이다.
- 영상 제공 종료 공지·콘텐츠 종료에 관한 기존 P2 기능은 유지한다. **영상 제공 종료와 30일 수강기간 만료는 서로 다른 상태**이며, 만료자의 새로운 제출·재제출을 허용하지 않는다. 구 '60% 완료자 제공 종료 후 재시청·최초 제출' 예외(D-05·R-05)는 D-42로 대체되었다.

### F-04. 3차시 영상 학습과 차시 완료

- 자체 업로드 영상의 각 차시는 학습 목표를 제시하고 실제 재생 시간이 해당 원본 영상 길이의 60% 이상이면 **그 차시를 완료**한다. 배속·반복·되감기 가능, 일시정지는 제외한다(기존 규칙).
- **차시 1·2·3은 동일 강의 내부의 별도 필수 학습**이며, **세 차시를 모두 완료**해야 최종 과제를 제출할 수 있다. 강의를 3개 수강한 것으로 집계하지 않는다. 강사의 분반과 무관하게 콘텐츠는 동일하다.
- 완료 뒤 자동 화면 전환은 하지 않고 학습자가 직접 다음 차시·최종 실습으로 이동한다. 수강 회차별로 진도·완료일을 독립 저장하며 **재수강 새 회차는 처음부터** 시작한다.
- 사용자의 이미 승인된 수료 강의는 정원을 반환했더라도 영상을 제한 없이 다시 볼 수 있다. 수료되지 않고 30일 만료한 회차는 기존 제출분 평가 외의 학습·신규 제출이 제한된다.
- 영상 총 파일 수·편성(차시당 단일 영상인지 등)은 PDF에서 독립적으로 확정하지 않았다. **9강의·총 27차시**만 기획 확정 수치로 기술한다.

### F-05. 최종 과제 제출·평가 시작·반려·재제출

| 사용자 동작/상태 | 허용 조건 및 결과 |
| --- | --- |
| 최초 제출 | 3차시 완료, 수강 확정부터 30일 이내, 원본 이미지 1~5장·장당 최대 50MB·모든 파일 정상 업로드 → **평가 대기(미수료)** |
| 평가 시작 전 수정/임시저장 | 수강기간 내 가능, **정식 새 제출이 아니므로 기존 7일 평가 마감 유지** |
| 강사 **평가 시작** | 담당 강사가 명시 클릭한 순간 **평가 진행 중**, 학습자 수정 잠금. 단순 열람은 잠금 아님 |
| 평가 시작 취소 | 평가 내용을 **아직 아무것도 쓰지 않은 현재 담당 강사만** 취소. 평가 대기 복귀, 기존 기한 유지, 기간 이내일 때만 학습자 수정 재허용 |
| 수료 승인 | **필수 공식 피드백 총 50자 이상 작성 + 현재 담당 전문강사 승인** → 수료 확정·배지·정원 반환·영상 무제한 재시청 |
| 반려 | 강사 **최소 길이 이상의 반려 사유 필수**(D-47, 수치 미정·추천 50자), 미수료. 30일 안에 수정 후 **재제출** 버튼으로 새 평가 요청 가능(횟수 상한 없음). 반려 사유는 일반 작품의 참고 피드백으로 연결 가능 |
| 정식 재제출 | 기간 내 반려 확정 후 가능, **새로운 7일 평가 기한**. 동시에 평가 대기 최종 과제는 수강 회차당 1건만 |
| 늦은 제출 안내 | 남은 수강기간이 7일 미만(수강 확정 후 23일 경과)이면 제출 화면에 **‘남은 기간이 평가 기한보다 짧아 반려 시 재제출 기회가 없을 수 있습니다’** 안내 표시(D-41) |
| 수강기간 만료 | 기간 내 제출 과제 평가는 만료 후에도 계속하며 정원 점유; 만료 후 새 제출/재제출 불가, 만료 뒤 반려면 정원 반환 |
| 수강 취소(E6) | **평가 대기·진행 중 수강 취소 불가**. 그 밖의 수강 중 상태는 취소 가능(‘다시 신청할 수 없음’ 확인) → **자리 반환 → 대기 1순위 자동 확정 + 사이트 알림**(D-54) |

- 공통 강사 교체 시 관리자는 **분반 담당 강사를 변경**한다(D-59, 구 D-40 분반 이동 대체). 변경 시 **작성 중 공식 피드백 초안도 새 담당 강사에게 승계**된다. 평가 잠금·기존 마감 유지, 이전 강사 수정권 상실. 담당 변경은 정원 반환 사유가 아니다. 개인 제작 강의는 전체 [확장]이다.
- 수료 후 과제 무효에 의한 **수료 철회·배지 유예·재수료 보완기간 정책은 폐기**한다. 기존 D-32의 *수료 확정 후 작성자 직접 삭제 → 수료 철회*도 현행 수료 철회 폐기 원칙과 충돌하므로 **삭제의 사후 수료/피드백 처리만 [미정]**으로 남긴다. 일반 작품 삭제는 별도 유지한다.
- 최종 과제 제목은 강의명 기반(작성자 수정 선택), 작품 기본 비공개. **수료 승인 이후 제출물 수정/삭제 허용 범위는 미확정**이며 기존 자동 수료 전제의 절차로 임의 적용하지 않는다.
- 지원 이미지 JPG/PNG/WebP, 원본 크기 초과·업로드 일부 실패 시 평가 대기도 생성하지 않는다. 압축·저장 구현은 `DEV_REVIEW.md`에서 설계한다.

### F-06. 강사 승인 수료·수준/마스터 배지·복습

- **3차시 완료만으로도, 과제 제출만으로도 수료되지 않는다.** 제출은 평가 대기이며 현재 담당 전문강사가 **필수 피드백을 작성하고 수료 승인한 시각**에 수료 확정한다. 반려되면 미수료다.
- 같은 취미·수준의 강사 승인된 인정 강의 **1개 이상** 수료하면 수준 배지, 입문/중급/고급 각각 1개 이상 승인 수료하면 마스터 배지. 같은 수준에 미수료·수강 중인 다른 강의가 있어도 기존 배지를 취소하지 않는다.
- 배지·작품별 댓글 자격은 기존 취미·수준 규칙을 따른다. 수료를 사후 철회·유예하는 기능은 **2026-10-30 폐기**되었으므로 관련 상태와 버튼을 만들지 않는다.
- 영상 차시 완료일·최종 제출일·정식 재제출일·평가 시작일·반려/수료 승인일은 서로 다른 사건이며 수료일은 승인일이다. 수료 확정 뒤에도 해당 영상은 **무제한 재시청** 가능하다.
- 추천 복습 차시·확인 기능은 기존 FR-032(P2) 우선순위를 유지하고 수료 조건과 분리한다.

### F-07. 작품 갤러리·개인 성장 기록

- **최종 과제 공개 게시물:** 유효 최종 과제의 게시판 보기이며 과제 원본과 연동한다(중복 과제 복제본이 아님).
- **일반 작품 게시물:** 최종 과제와 별도 여러 개 등록 가능. 각 글에 취미를 지정하고 **수준은 입문을 기본값**으로 적용한다. 취미 배지가 없으면 입문만, 있으면 현재 유효 배지의 최고 수준 이하(수료 철회·유예 기능은 폐기)만 선택한다. 수료 상태는 변하지 않는다.
- **[D-18·D-22] 일반 작품 제목/파일:** 제목을 직접 입력(필수)하고 JPG/PNG/WebP 이미지 **1~5장, 입력 원본 장당 50MB 이하**로 등록한다. 모두 유효하게 등록돼야 완료하며 일부라도 업로드 실패 시 등록 미완료(수료에는 영향 없음).
- 취미별 게시판에서 대분류/세부 취미 선택 및 검색·필터·정렬. 기본 정렬 최신 공개순, 정렬 최신/좋아요순, 필터 세부 취미·수준 태그·작품 유형, 검색 제목·작가 닉네임(P2, D-09).
- **[MVP 확정 성장 B]** 본인 최종 과제 + 일반 작품을 **날짜순**(최초 등록·유효 제출일 기준, 정상 수정은 순서 불변)으로 묶어 보여 주며 작품별 선택적 **한 줄 회고**를 기록한다. 작성 강제/수료 영향 없음. 작성자가 삭제한 일반 작품은 제외(수료 확정 과제의 삭제 후처리는 미정).
- **[D-14] 회고 안내문:** ‘이전 작업보다 나아진 점이나 여전히 아쉬운 점은 무엇인가요?’ — 선택 입력.
- **[D-13] 상단 요약:** 취미를 선택하면 선택한 취미 기준 **‘나의 첫 시작’(가장 이른 작품)·‘가장 최근 실습’(가장 늦은 작품) 썸네일 2개**. 다른 취미끼리 비교하지 않으며, 작품 1개면 1개만, 전체 보기에서는 미표시. 확대 비교·변화 분석은 확장.
- **[D-17 / D-12] 피드백 참조 저장:** 일반 작품 등록 화면에서 선택 취미에 대한 **본인의 가장 최근 공식 피드백 1개 전문**을 참고용으로 표시한다(부분 자동 추출 없음). 본인의 평가가 확정되어 접근 가능한 공식 피드백(**수료 승인 피드백 또는 반려 사유, D-47**)만 참조한다. 재수강으로 보관하지 않은 이전 회차의 반려 사유가 삭제되면 참고 연결도 해제한다(D-44). **관리자 작품 숨김 중에도 작성자 본인의 비공개 학습·성장 기록에서 원문 접근 허용(Q-02)**; 신고에 따른 공식 피드백 숨김·관리자 무효는 확장이다. 해당 취미에 유효한 공식 피드백이 없으면(과제 미제출·강사 작성 대기 등) ‘참고 가능한 최근 공식 피드백이 없습니다’ 안내를 노출하고 선택 체크박스는 비활성화한다. ‘이번 작품에 참고한 피드백’을 선택하고 등록하면 **작품↔공식 피드백 참조를 저장**하며, 성장 타임라인에서 해당 연결을 확인한다. **[확장 D-33] 피드백 자체 신고·숨김 정책은 확장**. 기존 관리자 과제 무효/무효 정정 정책은 폐기되었다. **MVP의 관리자 작품 숨김은 이와 달리 작성자 원문 열람을 유지**한다(Q-02). 관리자 재승인 후에는 최신 승인 내용을 참조해 보여 준다.
- **[D-32 변경 적용] 작품 삭제:** 일반 작품 삭제는 수료에 영향 없이 댓글·좋아요·참고 피드백 연결만 삭제한다. **수료 확정된 최종 과제 직접 삭제에 따른 자동 수료 철회는 폐기**하며, 그 후처리는 [미정]이다. 삭제된 일반 작품은 성장 기록에서 제외한다.
- 공개 프로필: **배지는 공개**, 학습 현황은 본인만 확인, 작품은 **선택 공개·기본 비공개**.
- 수강하지 않은 취미도 일반 작품으로는 등록 가능(**운영 중 세부 취미**에서 선택, D-29 — 준비 중·비공개 취미 불가, 이후 준비 중 전환돼도 기존 작품 유지; 배지가 없으므로 **수준은 입문 고정**). 최종 과제는 불가. 수준 태그는 강의 신청·수강 수준의 자유 선택과 별개이며, 게시물 등록·수준 수정 시점에 현재 자격을 확인한다.

### F-08. 작품 댓글·답글·좋아요

- 공개 작품은 로그인 회원이 열람·좋아요할 수 있다(신고는 확장 D-33). **본인 작품 좋아요 가능**.
- 한 계정의 작품당 좋아요 중복 방지, 취소·재등록 [기존 기본 규칙].
- [확장 D-33 전용 정책] 동일 대상·동일 사유의 진행 중 신고 병합 및 종결 후 무근거 재잠금 방지(D-24)는 신고 기능 도입 시 적용하며, MVP에서는 신고 접수 자체가 없으므로 적용하지 않는다. 상세 규칙은 05 §8 D-24.
- 댓글 작성 권한은 **해당 작품에 지정된 세부 취미·수준**과 현재 유효 배지로 판단한다(유예 기능 폐기).
- 낮은 수준 댓글: 입문 배지→입문, 중급 배지→입문/중급, 고급 배지→입문/중급/고급.
- 자기 댓글만 수정·삭제. 답글은 **1단계**만. 작성자는 자기 작품 댓글에 **배지와 상관없이 답글** 가능. **자발적으로 삭제한** 댓글 본문은 “삭제된 댓글입니다”로 대체하고 답글을 유지한다. **탈퇴만 한** 작성자의 정상 댓글은 **본문 식별정보를 비식별 처리한 후 원칙적으로 보존**하고 작성자명을 “--탈퇴한 사용자 입니다--”로 표시한다(D-25). 재식별 위험이 남으면 본문 전체를 대체·삭제하지만 답글은 유지한다. 둘이 겹치면 삭제 본문을 복원하지 않는다.
- 취미 분야 활동 권한만 있는 강사도 해당 분야 **공개 작품에 일반 댓글** 가능. 이는 비공개 제출물 열람·공식 피드백 권한과 다르다.

### F-09. 강사의 공식 평가·피드백·문의·알림

- 공통 강의는 **여러 분반을 운영**할 수 있다. 현재 평가 책임자는 **해당 수강이 배정된 분반의 전문강사 1명**이다(개인 제작 강의는 확장 D-45). 다른 강사와의 게시판 댓글은 가능하지만 공식 평가는 담당자만 한다.
- **평가 결과는 수료 승인 또는 반려.** 수료 승인은 공식 50자 이상 피드백 필수, 반려는 사유 필수. 잘한 점/개선할 점/다음 연습은 작성 가이드이며 각 칸 필수는 아니다. 관리자는 일반 과제 직접 승인·반려 권한이 없다.
- 최초 제출/반려 뒤 명시적 정식 재제출 시점에 **7×24시간 기한**을 부여한다. 수정·평가 시작 취소·담당 변경은 이를 초기화하지 않는다. 평가 기한이 **48시간 이하**면 마감 임박, 넘기면 기한 초과로 표시(평가 의무 지속).
- 강사가 과제를 단순 열람하면 아직 학습자 수정 가능. **평가 시작을 클릭**해야 수정 잠금. 평가 내용을 쓰기 전 본인이 시작 취소하면 다시 평가 대기 상태로 돌아가되 마감은 그대로다.
- 강사 변경 시 **미완료 평가와 작성 중 피드백 초안은 새 강사에게 인계**한다. 이미 최종 확정된 피드백은 기존 작성자·작성일을 보존하고 새 강사는 읽기 전용(기존 Q-04). 이전 담당자는 평가 수정 불가.
- [기존 기능] 비공개 최종 과제 문의는 현재 담당 강사에게 1:1 스레드, 공개 작품 질문은 댓글을 사용한다. **강사가 수강생에게 별도의 일방향 직접 알림·메시지를 발송하는 기능은 제공하지 않는다.** 최초 평가 완료 알림·피드백 이동은 FR-035(P0), 기타 알림의 FR 우선순위는 유지한다.
- 담당 강사가 없어진 분반은 **신규 배정에서 제외**하고(D-52), 관리자가 분반 담당 강사를 다른 적격 강사로 변경(D-59)하거나 관리자가 서비스 밖 운영용 이메일로 수동 안내(Q-03a 방식 A, 시스템 메일 알림 아님)하며, 과거 **평가 의무를 없애거나 기한을 재설정할 수 없다**. 공백 중 학습/제출의 허용 범위는 기존 운영 정책을 유지하되, 수료는 **평가 완료 전에는 불가**하다. 개인 제작 강사 이탈의 임시 평가자·기간 연장은 [확장]이다.

### F-10. 관리자 공개 작품 숨김·복구 [Q-01·Q-02 / MVP]

1. **대상·권한:** 관리자에게 공개 중인 최종 과제·일반 작품의 **숨김·복구만** 허용한다. 관리자 직접 삭제·댓글 단독 조치·과제 무효 판정은 MVP 범위 밖이다.
2. **숨김 상태:** 작품 공개 선택과 관리자 숨김 상태를 따로 판단한다. 일반 이용자는 목록·상세·파일 URL을 볼 수 없으나 **작성자 및 현재 담당 강사는 수료용 최종 과제·공식 피드백에 계속 접근**할 수 있다.
3. **학습 기록:** 관리자 숨김으로 **수료일·수준/마스터 배지·공식 피드백 작성 의무/168시간 기한·이미 작성한 피드백**은 변경되지 않는다.
4. **수정·복구:** 작성자는 정상 수정 가능하나 관리자 숨김을 해제하지 못한다. 복구는 관리자만 수행하고, 작성자가 비공개로 바꿨다면 복구 이후에도 일반 공개되지 않는다.
5. **안내:** 작성자 전용 비공개 화면(U-S16)에 공개 작품 숨김·복구 사유를 표시한다. 숨김·복구 사실은 **사이트 알림**으로만 알린다(이메일 알림 없음, D-57). **신고 결과 통지는 확장**, 관리자 무효→철회·오판 복구 통지는 폐기다.
6. **[확장]** 신고 접수·사건 병합·신고 중 수정 잠금. **[폐기]** 관리자 직권 과제 무효→수료 철회·배지 유예·무효 오판 복구·무효 원본 보관/파기. 신고 도입만으로 폐기된 제재를 복원하지 않는다.

**구분:** 작성자 **일반 작품 삭제**는 P2로 유지한다. **수료 승인된 최종 과제 직접 삭제→수료 철회는 폐기**됐으며, 승인 후 삭제 가능 여부·후처리는 미정이다.

### F-11. 카테고리와 콘텐츠 운영 — **이번 MVP는 시드 데이터(D-59)**

- **[D-59]** 대분류·세부 취미·상태, 초기 9강의·27차시·최종 과제·영상은 **검수 완료된 시드 데이터로 입력**한다. 아래 관리자 CRUD·검수 화면 규칙은 후속 도입 시 적용한다.

- 대분류/세부 취미의 등록·수정·삭제·복구·상태 변경. 상태를 선택하지 않으면 **비공개 초안**.
- 새 세부 취미의 운영 공개 조건: 입문/중급/고급 각각 공개 가능한 강의 최소 1개. 운영 중 대분류는 운영 가능한 하위 취미 최소 1개.
- 대분류 비공개→하위 숨김; 재공개 시 하위는 관리자가 재지정. 카테고리 이름 수정 시 내부 식별자/학습 기록 유지. 복구만으로 강의 재공개 금지. 운영 하위 취미가 없어진 운영 중 대분류는 자동 변경하지 않고 관리자 화면에 상태 재설정 필요를 표시(D-31).
- 초기 콘텐츠(9강의/각 3차시·총 27차시, 영상 파일 총수 미정)는 운영 측 직접 준비/업로드, **관리자 최종 검수·공개 승인**.
- 신규 세부 취미의 강의·영상도 운영 측이 DB 입력으로 추가하고, 관리자는 검수·승인 후 운영 전환한다. 관리자 강의·영상 등록 화면은 **확장(D-01)**이다.
- 제공 종료 **1개월 전 공지** 후 종료일부터 신규 신청을 제한한다. 영상 접근은 **수강 30일 이내 또는 수료자**(D-42): 미수료자의 시청·제출·수정·재제출은 **기존 수강 확정일부터 30일 안에서만**, **수료 승인된 학습자는 무제한 재시청**. 구 60% 완료자 예외(D-05·R-05)는 대체. 필수 수준 강의가 제공 불가능하면 취미를 준비 중으로 전환; 과거 수료는 유지.

### F-12. 전문 강사 계정·공통 분반(생성·담당·정원)

- **[D-51]** 관리자는 아이디·실명·이메일을 입력해 **임시 비밀번호**와 함께 전문강사 계정을 **즉시 생성(활성)**하고 (임시 비밀번호는 시스템이 생성해 생성 직후 화면에 1회만 표시), 세부 취미별 자격을 부여한다. 메일 설정 링크는 없다. 강사는 첫 로그인 시 새 비밀번호로 변경해야 하며, 분실 시 관리자가 임시 비밀번호를 재발급한다. 계정 상태: `첫 로그인 전(임시 비밀번호) → 활성 → 비활성`.
- **[D-59] 분반 관리:** 관리자는 공통 강의마다 분반을 **생성**하고 **담당 강사 1명**과 **정원(1~30)**을 지정·변경한다. 정원은 현재 활성 수강 수 아래로 줄일 수 없고, 정원을 늘리면 늘어난 자리만큼 대기 1순위부터 자동 확정한다.
- **공통 강의:** 같은 콘텐츠를 여러 강사가 분반별 담당한다. 각 분반 정원 1~30건, **강사 합산 30건 검사 없음**(D-52). 강사 교체·정지·이탈 시 관리자는 **분반 담당 강사를 변경**한다(D-59, 수강생 분반 이동 없음).
- **[확장 D-45] 개인 제작:** 강사의 강의 제작·등록, 강의별 자율 정원, 합산 상한 없음은 확장 도입 시 정책으로 보존한다. MVP에는 기능이 없다.
- 이미 평가 시작 상태여도 담당 변경 시 잠금·작성 중 피드백·7일 기한을 유지한다. 새 담당 강사가 해당 과제의 유일한 공식 최종 평가자다. 새 담당의 경고 판정에는 인계 후 유예 시간을 적용한다(D-43).
- **[확장]** 개인 제작 강사의 이탈 시 신규 신청·초대 중지, 관리자의 학습기간 연장, 적격 임시 평가 강사 지정, 강의 운영 종료·학습 기회 복구(Q21~Q25). 관리자는 직접 공식 평가자가 되지 않는다.

### F-13. 탈퇴·삭제와 익명 기록

- 사용자 탈퇴 시 본인 계정·개인 수강/진도/수료/배지/복습/공식 피드백·최종 과제/일반 작품 원본 및 공개 글 삭제.
- 타인 작품의 자발 삭제하지 않은 댓글은 **본문 내 식별정보를 사전 확인·마스킹한 뒤 계정 참조 없이 익명 보존**한다(D-25). 부분 비식별로 재식별 우려가 남으면 **본문 전체 비공개/삭제·대체**, 원 댓글 자리와 타인 답글은 유지한다. 표시명 `--탈퇴한 사용자 입니다--`. 자발 삭제한 댓글은 `삭제된 댓글입니다` 유지하며 복원하지 않는다.
- 기존 좋아요 반응/집계를 익명으로 유지하되 회원별 중복 검사/취소 연계는 삭제.
- [확장 D-33] 완료된 일반 신고는 삭제; 진행 중 신고·필요 증거 및 최소 식별자는 처리 완료까지 예외 보관.
- 로그인 차단, 식별·인증정보 및 개인 학습·작품 삭제. 이메일 원문은 삭제하고 재가입 제한 **확인값**만 30일 보관한다. 1:1 문의는 삭제한다(신고 중 스레드 예외 보존은 확장 D-33).
- [확장 D-33] 탈퇴자가 신고당한 쪽이어도 진행 중 신고 대상 작품·댓글·문의 스레드는 처리 완료까지 필요한 최소 범위를 비공개 보존 후 삭제한다. 탈퇴 뒤 신고 없이 보존한 개인 문의는 남기지 않는다.

### F-14. 학습자→담당 강사 1:1 문의

- 학습자는 수강 중이거나 수료한 강의의 **현재 담당 강사**에게 문의 스레드를 만들고, 강사가 답변한다.
- 비공개 과제에 대한 질문은 1:1 문의, 공개 작품에 대한 질문은 댓글을 쓴다. 학습자 간 메시지는 MVP 제외.
- 새 문의·답변은 알림함에 표시. 담당 변경 시 새 담당 강사가 기존 스레드를 이어받는다 [확정 D-08]. 담당 강사가 없는 동안에는 새 스레드·메시지 작성 불가 안내 [확정 D-31].
- 텍스트만(첨부 없음). 답변은 1주일 내 권장 안내만 두며 경고 대상 아님. 학습자 탈퇴 시 스레드 삭제. [확장 D-33] 문의 신고와 신고 중 스레드의 비공개 임시 보존 후 삭제.

### F-15. 평가 기한 초과·기존 경고 제도(P2)

- **평가 미완료의 고정 마감은 최초 제출 또는 정식 재제출 시각부터 7×24시간**이다. 마감까지 48시간 이하면 임박, 이미 지났으면 초과 표시. 기한을 넘어도 평가해야 한다.
- 기존 관리자 경고·담당 자격 정지 기능은 **FR-044(P2)의 우선순위를 유지**하나, 제출물 수정·평가 시작 취소·강사 인계로 기한 재시작 또는 지연 실적 삭제를 인정하지 않는다. 기존 경고의 분기 집계 등 비충돌 원칙은 유지한다.
- **공통 강사 과부하:** 평가 대기 건수와 남은 평가 기한을 함께 검토하되 구체적 수치·AND/OR 조합은 미정(U10). 개인 제작 강사 지연 대응(Q28·U12)은 [확장 D-45].

### F-16. 강사 LMS·통계 [P0 · D-58]

- 강사 로그인 첫 화면에 **본인 담당 강의·분반 목록**을 표시한다.
- 강사는 담당 수강생의 **이름·수강 강의·진도율·남은 수강기간·과제 상태·차시별 완료·제출 및 피드백 이력**을 확인할 수 있다. 타 강사 분반의 개인 수강생 데이터 열람은 허용하지 않는다.
- 과제 평가는 **대기/진행 중/완료** 탭으로 나누고, 임박(48시간 이하)/기한 초과 **경고**를 표시한다. 흐름은 **평가 시작(수정 잠금) → 피드백 초안 저장 → 승인/반려**, 내용 작성 전 시작 취소 가능(D-56). 승인·반려는 F-09의 전문강사 권한으로 수행한다.
- **P0 통계(D-58)**는 본인과 관리자만 열람: **현재 숫자만 — 담당 분반별 수강 중·수료·반려·평가 대기 수.** 월별 추이·수료율·평균 진도율·과거 운영 실적은 후속. 수강생 공개 금지.

### F-17. 공통 강의 단일 대기열(FIFO)·자동 확정 [확정 운영 정책 · D-53]

- **[FR-053 P0]** F-03의 강의 단일 대기열, 선착순(FIFO) 순번, 자리 반환 즉시 **대기 1순위 자동 수강 확정**(분반은 D-52 규칙), **사이트 알림**(이메일 없음), 대기 취소 후 끝순번, 동일 강의 재신청 불가를 일관되게 적용한다. 초대·수락·48시간 단계는 없다.
- **관리자 대기열 조회(D-59):** 강의별 대기 인원·순번·대기 신청 시각과 분반별 남은 자리를 **조회만** 한다(순번 변경·수동 확정 없음).
- **정원 점유:** 학습/평가 대기/진행/기간 내 반려 및 재제출 대기는 계속 점유. **수료 승인** 또는 **30일 만료·대기 평가 없음**, **30일 만료 후 최종 반려**, **허용된 자발 취소**에서 반환하고, 반환 즉시 대기 1순위를 자동 확정한다(D-54). 평가 미완료인 30일 만료는 **평가 완료까지 점유**.
- **[확장 D-37]** 기간 만료 이후 오반려를 수료 승인으로 바로잡는 기능은 MVP에 없다. 도입 시에도 이미 반환한 자리는 재점유하지 않는다(자동 확정된 다음 학습자 보호).

### F-18. 재신청 불가 [확정 운영 정책 · D-55]

- **[D-55 · 현행]** **같은 강의는 한 번만 수강한다.** 수료한 강의(D-35)는 물론 **취소·만료한 강의도 이번 MVP에서는 재신청·대기 불가**. 세부 취미 화면의 신청 버튼 자리에 ‘수료한 강의 / 취소한 강의 / 기간이 만료된 강의는 다시 신청할 수 없습니다’를 표시한다.
- **[보류 · 아래는 재신청 허용 시 재검토할 이력]**

- 취소·반려된 강의의 **직전 수강 확정 시각+30일** 이전에는 **동일 강의 대기/신청 불가**. 30일 경과 뒤에도 이전 회차 최종 평가가 미확정이면 불가. 30일 지난 뒤 반려 확정되면 그 순간 재신청 가능(반려일 기준 30일 재기산 금지). 만석이면 우선권 없이 끝순번.
- 새 수강 회차는 **3차시 진도·제출 과제를 이어받지 않고 처음부터** 시작하며 기존 개별 기록·과제는 삭제한다. **기집계된 월별 강사 수강/수료/반려 실적은 유지**한다.
- **[확정 D-35]** 수료한 강의는 재수강할 수 없으므로 이 흐름은 미수료(만료·취소·반려) 회차에만 적용된다. U03(배지 처리)은 종결.
- **[확정 D-36=U04 B]** 이전 기록 삭제는 **새 수강 회차가 확정되는 순간**(즉시 확정 또는 초대 수락) 실행한다. 대기 신청·초대 발급·초대 미수락·대기 취소로는 삭제하지 않는다.
- **[확정 D-44=U01 · FR-056 등급 미정]** 새 회차 확정 전 학습자는 **‘이전 시도를 일반 작품으로 보관’**을 선택할 수 있다. 보관 시 이미지·설명·회고·공개 상태·타인 댓글/좋아요·반려 사유 원문(참고 연결 포함)이 본인 일반 작품으로 이동하며 수료·배지와 무관하다. 미선택 시 이전 과제·반려 사유는 삭제하되, 공개 게시물에 타인 댓글이 있으면 ‘작성자가 삭제한 작품입니다’ 자리 표시로 타인 댓글·답글을 보존한다(D-25 원칙 우선).
- 관리자 감사 이력 처리(U02)만 미정. 오반려 정정(U05 포함)은 [확장 D-37].
